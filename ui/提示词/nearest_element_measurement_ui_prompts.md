# 两个元素自动找出最近点测量 —— UI 方案与 OpenCLI 提示词包

## 1. 功能定位

这是一个**半自动测量模式**：

- 不是手动点两点
- 不是批量净距分析
- 而是：**用户选择两个元素，系统自动解算两者最近点，并生成一条正式距离标注**

它应处在现有两类能力之间：

1. **手动点测量模式**  
   当前仓库里，`useXeokitMeasurementTools.ts` 已经有“第一击创建、hover 预览、第二击完成、点空白取消”的距离/角度测量交互骨架。  
   来源：<https://github.com/happyrust/plant3d-web/blob/main/src/composables/useXeokitMeasurementTools.ts>

2. **自动结果导向模式**  
   当前仓库里，`usePipeDistanceStore.ts` 已经有“选择元素集合、设置参数、运行检测、展示结果列表、激活结果”的结果型流程。  
   来源：<https://github.com/happyrust/plant3d-web/blob/main/src/composables/usePipeDistanceStore.ts>

因此，这个新 UI 最合理的形态是：

> **单次两元素测量工作流**
> 选择 A → 选择 B → 自动求最近点 → 生成尺寸 → 可保存到校审记录

---

## 2. 设计目标

请围绕以下目标做 UI：

1. 让用户非常清楚现在是在“选元素”而不是“点空间中的点”
2. 降低误选成本，支持替换 A / 替换 B
3. 最近点计算过程可见，避免用户误以为系统卡住
4. 结果生成后要能快速看懂：两个元素是谁、最近点在哪里、距离是多少
5. 结果可继续进入“保存 / 复测 / 删除 / 飞到结果 / 生成截图”
6. 为后续扩展到“管道-结构”“元素-元素”“版本差异中的最近点对比”保留结构

---

## 3. 推荐页面结构

建议做成 **三栏式测量工作台**，但以三维视图为主：

### A. 顶部工具条
包含：
- 最近点测量
- 手动距离
- 角度
- 标高
- 自动净距
- 清空
- 撤销
- 退出

其中“最近点测量”高亮为当前模式。

### B. 中央三维视图
职责：
- 选择第一个元素 A
- 选择第二个元素 B
- 高亮当前已选元素
- 显示最近点连线与尺寸标注
- 支持飞到结果
- 支持 hover 提示

### C. 右侧结果/属性面板
拆成 4 个区块：

1. **当前模式说明**
   - 模式名称：两个元素最近点测量
   - 操作步骤：先选元素 A，再选元素 B

2. **已选元素**
   - 元素 A 卡片
   - 元素 B 卡片
   - 每张卡片显示：名称、类型、专业、refno、定位按钮、替换按钮、清除按钮

3. **计算设置**
   - 测量模式：表面到表面 / 中心线到中心线 / 包络到包络
   - 容差
   - 是否吸附关键点
   - 是否忽略隐藏对象
   - 是否生成正式标注

4. **结果区域**
   - 当前距离值
   - 最近点坐标 A/B
   - 结果状态
   - 操作按钮：保存、复测、飞到结果、截图、删除

### D. 底部状态栏
显示：
- 当前步骤
- 快捷键提示
- 命中状态
- 错误提示
- Esc 退出说明

## 4. 推荐交互流程

## 流程 1：标准测量

### 步骤 1：进入模式
用户点击“最近点测量”。

UI 反馈：
- 顶部工具按钮高亮
- 右侧面板展示“步骤 1：请选择第一个元素”
- 底部状态栏提示：左键选择元素，Esc 退出

### 步骤 2：选择元素 A
用户在三维场景中点击一个元素。

UI 反馈：
- 元素 A 高亮
- 面板中生成 A 卡片
- 状态切换为“步骤 2：请选择第二个元素”
- 三维中可保留 A 的描边/半透明强调

### 步骤 3：选择元素 B
用户点击第二个元素。

UI 反馈：
- 元素 B 高亮
- 面板中生成 B 卡片
- 自动进入“计算中”状态

### 步骤 4：系统自动计算最近点
系统调用几何服务，自动求两元素最近点。

UI 反馈：
- 右侧结果区显示 loading
- 顶部或场景中显示细小进度提示：正在计算最近点…
- 暂时禁用“保存”按钮
- 可允许用户取消本次计算

### 步骤 5：展示结果
计算成功后：
- 在两个元素之间显示最近点连线
- 自动绘制尺寸标注
- 显示距离值
- 显示两个最近点的小型 marker
- 右侧显示详细信息

### 步骤 6：后续操作
用户可：
- 保存为正式测量
- 飞到结果
- 重新测量
- 替换 A/B
- 删除当前结果
- 截图挂到校审记录

## 5. 推荐状态机

这个功能最重要的是状态要清楚。

### 状态 A：空闲未开始
- 未选择任何元素
- 右侧显示操作说明
- 主按钮：开始选择

### 状态 B：已选择 A，等待选择 B
- A 卡片已锁定
- B 卡片为空占位
- 场景中高亮 A
- 主提示：请选择第二个元素

### 状态 C：A/B 已选，计算中
- A/B 都锁定
- 显示 loading
- 禁止重复点击保存
- 允许取消计算或重新选取

### 状态 D：结果已生成
- 尺寸线、箭头、文字、最近点 marker 可见
- 右侧展示结果卡
- 支持保存 / 飞到 / 截图 / 删除 / 复测

### 状态 E：计算失败
常见原因：
- 元素几何缺失
- 元素不可参与最近点计算
- 服务超时
- 两个元素实际上是同一对象

UI 反馈：
- 红色错误条
- “重新计算”按钮
- “替换元素”按钮
- 不要直接清空 A/B，避免用户重新选择

### 状态 F：已保存
- 结果进入正式记录
- 可从“临时结果”切换为“已保存”
- 支持再次编辑或复制为新测量

## 7. 视觉与交互规则

### 7.1 场景中的强调方式
- 元素 A：蓝色高亮
- 元素 B：橙色高亮
- 最近点 marker：亮色圆点
- 最近点连线：高对比但不过分粗
- 结果激活时：整条尺寸线更亮

### 7.2 尺寸标注要求
当前仓库里 `LinearDimension3D` 已经强调了：
- extension line overshoot
- arrow plane normal
- label trim
- 屏幕方向可读性

来源：  
<https://github.com/happyrust/plant3d-web/blob/main/LINEARDIMENSION3D_SOLVESPACE_ALIGNMENT_REPORT.md>

所以这个新 UI 不要再自创另一套标注视觉语言，应直接复用现有三维尺寸样式体系。

### 7.3 鼠标行为
- 左键：选元素
- Hover：预高亮、显示元素摘要
- 右键：替换当前元素 / 清除当前结果 / 飞到元素
- 双击：飞到当前元素
- Esc：退出模式或取消当前选择阶段

## 9. 微文案建议

### 空状态
- 请选择第一个元素
- 已选中元素 A，请继续选择元素 B
- 正在计算两个元素的最近点
- 最近点已生成，可保存为正式测量

### 错误状态
- 该元素当前不支持最近点解算
- 无法计算这两个元素的最近点，请尝试替换其中一个元素
- 计算超时，请重试
- 请选择两个不同的元素

### 成功状态
- 已生成最近点尺寸
- 已保存到当前校审记录
- 已定位到测量结果

## 16. 我对这个功能的最终建议

不要把它设计成“简化版两点测量”，而要设计成一个独立模式：

- 输入对象是 **元素**
- 输出结果是 **系统解算后的最近点尺寸**
- 交互中心是 **已选元素卡片 + 结果卡片**
- 场景角色是 **高亮 / marker / 飞到结果**
- 成果要能进入 **校审记录**

这样它和你后面的：
- 管道与结构自动标注
- 管道与管道自动净距
- 差异位置对比测量
都能复用同一套 UI 骨架。
