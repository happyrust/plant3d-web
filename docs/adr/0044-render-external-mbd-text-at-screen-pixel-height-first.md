# 外部 MBD 图元首版沿用屏幕像素字高

MBD/PDMS 以世界毫米字高出图（生产 cheight=100mm，小尺寸会缩字高），而尺寸呈现内核以屏幕像素字高绘制文字以保证任意视距可读。决定首版让外部 MBD 图元沿用屏幕像素字高、与用户尺寸视觉一致，适配层保留契约中的 cheight 信息不丢弃；按世界字高渲染的模式作为后置可选项，仅在需要与 PDMS 出图做 1:1 视觉验收时实现。后果：验收该模式之前，截图无法与 PDMS 直接比对文字尺寸与避让效果。

依据：ADR 0041、ADR 0012（LFF 矢量字形）、`rs-mbd` 契约 `MbdV2Meta.cheight_mm`。
