# 批注截图取自场景并把编号徽标画进场景

批注代表截图直接读取 WebGL 主画布，不做 DOM 合成；为使截图可分辨批注归属，批注编号徽标（A1/C 等）从 HTML 角标迁移为场景图元（沿用尺寸系统 LFF 矢量字形，ADR-0048 方向），随场景自然进入截图。批注标题与描述文字卡片明确不进入截图——文字由批注面板、表格视图与 PMS 表单承担。

备选「维持纯模型视角（无编号）」被否决：同视口多条批注时截图无法分辨归属；备选「WebGL+DOM 所见即所得合成」被否决：html2canvas/SVG 序列化兼容性与性能风险高，且与本仓库「把视觉元素画进场景」的既定演进方向相悖。
