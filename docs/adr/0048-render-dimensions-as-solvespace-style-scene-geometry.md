# 尺寸采用 SolveSpace 风格的三维场景图元呈现

尺寸线、箭头和 LFF 矢量文字进入与模型相同的 Three.js/WebGL 场景，以设计坐标锚定，使用随相机更新的观察平面和屏幕恒定尺度，并按 SolveSpace `FRONT` 层语义默认置于模型之前。该决定以三维场景中的稳定工程表达替代独立 Canvas2D overlay，取代 ADR 0011 以及 ADR 0041 中绑定 Canvas2D 的实现部分，同时保留 ADR 0010、0012、0017、0044 的置顶、字体、失效驱动和屏幕字高语义。

Canvas2D 的优点是批量简单、截图和 SVG 输出直接，但它无法表达用户要求的三维场景关系；固定世界平面和深度遮挡又会导致远距离文字缩小或被设备遮住。新画家必须批量提交场景几何并复用资源，不能恢复为每条尺寸一个独立 Object3D 的旧实现。

本次删除边界只覆盖绘制底层：移除 Canvas2D overlay 绘制链，以及旧的逐尺寸 `Object3D + CSS2D` 实现。尺寸文档、业务模型、持久化、MBD 适配、交互协议、主题和 LFF 字体解析继续复用；新的单一批处理 Three.js 场景画家成为唯一生产渲染入口。

布局采用“设计锚点固定、显示平面随相机”的模型。测量点、轴、半径和用户拖拽产生的米制语义位置继续持久化；相机变化只重算视图对齐的呈现。自动碰撞避让是当前视口的临时显示偏移，不写回尺寸文档。

替换在现有 `DimensionPainter` 边界内逐类完成，待线性、角度、径向和外部 MBD 图元均通过视觉与性能验收后原子切换。生产构建不保留双渲染器或长期 feature flag；切换提交同时删除 Canvas overlay 和旧的逐对象标注类。

性能继续执行 ADR 0040 的 10,000 条已加载、2,000 条可见、尺寸更新链 p95 不超过 16 ms、命中测试 p95 不超过 2 ms 的预算。`Object3D`、几何体、材质和 draw call 数量只能随样式批次增长，不能随尺寸数量增长；命中测试继续复用屏幕空间索引，不为每个尺寸或字形创建可射线拾取对象。

文字采用工程制图朝向：尺寸值沿尺寸线方向排布，并自动翻转到可读方向；设备编号、坐标和多行说明保持视口水平。两者都使用同一随相机更新的三维显示平面。

三维场景图元是布局的权威结果：内核直接产出三维线段、箭头、圆弧和 LFF 字形顶点，二维投影仅服务于碰撞、命中和 SVG 导出。不得把旧 Canvas 屏幕图元反投影为 WebGL 几何；迁移完成后删除旧 `LayoutPrimitive` 屏幕绘制契约。

文字区域按 SolveSpace 的字形边界留白，尺寸线和引线不得穿过文字。默认不绘制不透明底板、CSS 标签或文字 Sprite；只有外部 MBD 图元明确表达的编号框、参考框才绘制边框。

默认工程标注色改为参考图风格的深红色；悬停使用黄色，选中使用亮红色，失效和近似状态保留独立警示色。颜色只由尺寸主题提供，不写入着色器常量或业务数据。

相机交互采用两级更新：运动期间只更新共享相机基向量和像素尺度，使三维批次连续跟随，不重跑全量碰撞；相机停稳后再执行一次布局与避让。接受运动期间短暂的文字重叠，以保证交互帧预算。

统一画家覆盖尺寸文档中的用户尺寸，以及 BRAN、MBD v1/v2 提供的线、圆弧、箭头、标记、文字和参考框。DTX 云图、焊缝工具等不属于尺寸文档的独立 Viewer 标注不在本次迁移和删除范围内。

现有测量工具通过 `MeasurementAnnotationManager` 创建的线性和角度结果也接入统一画家；迁移后删除该路径中的 `AlignedDimension`、`AngleDimension` 和 CSS2D 尺寸标签。`useXeokitMeasurementTools` 的距离、角度、高程点和高程差结果同样改为统一画家的只读输入，并删除 `XeokitDistanceMeasurement`、`XeokitAngleMeasurement`、`XeokitElevationPointMeasurement`、`XeokitElevationDeltaMeasurement` 的 Line2/CSS2D 渲染部分；Xeokit 拾取、吸附和测量计算继续复用。共享标注系统仍保留给焊缝、坡度和普通引线等非尺寸工具。

`PipeDistanceResult` 也注册为统一画家的只读外部尺寸源，删除 `usePipeDistanceAnnotationThree` 的独立 `Line + Sprite + Object3D` 绘制；管道间距检测、Store 和 Drawer 保持不变。

线性、角度和径向尺寸默认使用固定屏幕尺寸的实心三角箭头；空间不足时自动翻到尺寸线外侧，延伸线越界长度同样保持固定屏幕尺度。外部 MBD 已明确提供箭头线段时尊重源数据，不重复生成箭头。

用户尺寸持久化 `labelPinned`。新建尺寸默认参与自动避让；用户拖拽标签后固定其米制语义位置，不再被自动碰撞移动，直到执行“恢复自动布局”。旧文档迁移时默认 `labelPinned=false`。

验收采用双证据：三维图元、测量值、锚点、箭头方向和投影命中使用确定性 golden 与明确数值容差；固定相机截图使用允许抗锯齿差异的视觉回归。发布门槛必须覆盖 AMS 7997、BRAN `24381_145018`、不同版本最小交付单元加载，以及 ADR 0040 的 10k/2k 性能基准。

版本分屏为 A、B 分别生成版本尺寸批次，并随对应模型 render pass 显隐。外部 BRAN/MBD 标注使用各版本数据；用户尺寸分别解析两侧语义锚点，一侧解析失败只在该侧显示失效状态。禁止把当前版本的一份尺寸几何复制到两侧。
