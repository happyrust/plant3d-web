# MBD 非尺寸图元经尺寸呈现内核渲染而不新建独立渲染层

MBD V2 契约共 11 种图元，其中 9 种（标签、引线、辅助线/弧/圆/点/文字、焊缝符号、坡度符号）不是尺寸标注。决定让全部 11 种图元统一经尺寸系统的共享呈现内核渲染（同一 Canvas 画家、命中索引、截图与 SVG 导出链路，遵守 ADR 0011），而不是为非尺寸图元新建独立渲染层；同时在领域上把它们区分为「外部尺寸」（LinearDim/AngleDim）与「外部标注图元」（其余 9 种），后者只读、不进入用户尺寸文档，维持 ADR 0002 与迁移设计文档的领域边界。代价是呈现内核需要扩展弧/圆/点/符号等显式图元原语；替代方案（独立 MBD 渲染层）会重复画家、命中和导出三套基建，被否决。

依据：`rs-mbd/crates/rs-mbd/src/contract.rs`（冻结契约）、ADR 0002、ADR 0011、ADR 0028。
