# 呈现内核只新增弧与点两种原生原语

为承接 MBD 外部标注图元，呈现内核在直线段与文字之外只新增弧（整圆作为闭合弧）和点标记两种原生原语，并给显式图元增加逐图元线型（solid/dashed/dash_dot）；焊缝、坡度等符号由适配层用弧、线、点、文字拼装，多行标签由适配层拆行为多个文字图元。弧与圆必须原生的原因是折线逼近会造成 SVG 导出膨胀、虚线沿折线断裂和命中区域粗糙；符号形状固定且种类少，专用原语的维护成本高于拼装。代价是画家、SVG 导出、命中索引和 golden 测试需同步扩展。

依据：ADR 0041、ADR 0003（纯布局加薄画家）、ADR 0031（PNG/SVG 导出）。
