# 以 SolveSpace 布局语义为尺寸样式基线

新布局引擎对 SolveSpace `drawconstraint.cpp` 做语义级 1:1 移植：界线过 ref 垂直于测量线并超出箭头 10px、箭头 13px 长 18° 半角、文字包围盒各留 8px 对尺寸线切分或外延、文字外置时箭头反向加 18px 外延段、角度弧最小半径 15px 且随文字外置做弧外延、径向尺寸使用 ⌀/R 前缀、参考尺寸虚线加 REF 后缀。这些算法照搬，常数作为样式默认值暴露为可调参数；SolveSpace 的正交等比投影换成在标注深度处的 worldPerPixel 逐点换算，是唯一的相机模型适配。

验收基准是布局函数输出图元的快照测试（golden），不做与 SolveSpace 截图的像素级对比，也不允许退化为「仅参考观感」的自由实现，从而让「像不像」变成可判定命题。
