# 代表截图生命周期从属批注且每批注仅一张

每条批注持有至多一张代表截图：重拍即覆盖并异步清理旧附件；删除批注时级联删除其代表截图附件（失败仅 toast 警告不阻断），修复「重拍删旧图、删批注留孤儿」的不对称。已提交进工作流的批注受既有门控保护，不触发级联删除。

云线创建完成后立即自动拍摄的行为保留（此刻视角上下文最准），补充一项：标题/描述编辑提交后同步更新附件 description 元数据。多视角需求由任务级手动截图（kind=manual）承担，不引入批注级多张画廊——面板、表格、PMS 表单与四条恢复链路都无需改成列表语义。

备选「附件保留作审计痕迹」被否决：与重拍删旧图矛盾，且草稿期误建批注会永久污染任务附件列表；备选「延迟到标题填写后再拍」被否决：用户可能已离开视角，截图证据价值下降。
