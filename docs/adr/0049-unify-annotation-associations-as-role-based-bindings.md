# 批注关联统一为带角色绑定

四类批注（text/cloud/rect/obb）的模型关联统一收敛到云线已有的带角色绑定结构（anchor=批注锚点、member=问题目标元素），废弃 text 单 `refno` 与 rect/obb 裸 `objectIds` 的扁平语义。text 批注创建时点击命中的构件默认同时写入 anchor 与 member 两条绑定（双角色），存量行为不变、语义显式化；锚点不构成批注关联，反查与统计只看 member。

统一后，模型元素→批注的反查覆盖全部批注类型的 member 绑定（不再仅云线），锚点一律不参与反查。

被否决的备选：维持现状（锚定即关联）延续 cloud 与 text 的语义矛盾，且点在参考位置时误绑；锚点不自动成为问题对象（关联须显式选择）语义最干净，但会把存量 text 批注的关联全部降级为无关联。
