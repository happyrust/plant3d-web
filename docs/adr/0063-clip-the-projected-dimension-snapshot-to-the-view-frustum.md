# 尺寸布局的二维投影快照按视锥裁剪：跟 GPU 同一条裁剪线，被整个裁掉的图元留空位占坑，视锥外的标签不排、不探

ADR 0048 把三维场景图元定为布局的权威结果，二维投影（`LayoutResult.primitives`、`labelBounds`、`hitRegions`）只服务于碰撞、命中与 SVG 导出。这份快照此前把每个锚点**直接投影**：透视相机把相机背后的点投到一个有限的**镜像**位置（齐次除法丢掉了 `w` 的符号，深度却 > 1），于是近景相机钻进管子时，一条越过相机的尺寸线在快照里是一根穿过屏幕的幻影线段——可被命中；相机背后的数值文字在屏内占一块幻影 `labelBounds`——被避让、被去重、被当成标签体的障碍；SVG 导出多出一堆画到虚空的描边。画家不受影响（顶点交给 GPU，GPU 在齐次空间正确裁剪），所以看得见的画面一直是对的，错的只有看不见的那份快照（全管道扫描 2026-09-14 留下的「仍留」项）。

决定（2026-09-14）：**二维快照按 GPU 的裁剪口径裁**。`kernel/geometry/sceneGeometry.ts::projectScenePrimitive`：一个顶点「可见」= 它的锚点投影到有限位置且深度落在 `[−1, 1]`（相机背后、近平面之前、远平面之外都不可见——深度判据而不是位置判据，正是因为镜像点的位置是有限的）。线段一端可见一端不可见时，在可见性谓词上二分 32 步找到离开视锥的点并在那里截断（锚点与屏幕偏移一起线性插值）；开放折线按同法切成若干段、只留最长一段（一条 path 一条 dash 流，ADR 0042）；闭合轮廓与填充按 Sutherland–Hodgman 对视锥边界裁成新多边形；箭头三角、标记点、字形（含三维 framed 文字的四个框点）是围着一个锚点的几个像素，整体画或整体不画。**被整个裁掉的图元不删，留一个空位占坑**：线段两端、标记点、字形原点停在 `CLIPPED_SCREEN_POINT`（−1e6, −1e6，任何视口之外）、宽高为零，路径点列为空——场景图元与投影图元的顺序对应（三角形 → 三条边、其余一一对应）是碰撞 pass 搬标签与 SVG 分辨实心箭头所依赖的，不能因为裁剪错位；`isClippedPrimitive` 给 SVG 导出识别并跳过这些占坑，测量类消费者（命中索引、占用网格、障碍描边）在那里本来就量不到东西。可见路径上每个顶点仍然只投影一次（可见性与位置来自同一次 `project`），只有真被裁到的线段多付二分的代价。

跟着这条口径的两处：`planTagBillboard` 对锚点不在视锥内的标签直接给空布局——标签体的每个顶点都挂在同一个三维锚点上，GPU 会把整块裁掉，快照不该把一块镜像的标签体停在屏内占位；求解器的标签位置只用来定首选方向，它在相机背后时忽略、退到向上。`markOcclusion` 对探测点不在视锥内的记录不发射线、直接 `occluded = false`——它没有像素可以穿，画家也不会画它，它不是被几何挡住而是不在视野里。

被否决的替代：把相机背后的顶点在上游剔掉（同一条记录一半在背后、一半正画在屏上，整条剔掉丢的是屏上那半的命中——全管道扫描时已否决）；让 `ViewportProjector` 多暴露相机空间深度或近平面距离来解析求交（接口要动、测试投影器要跟、正交相机另算一套；深度谓词 + 二分不动接口且天然与 GPU 的 near / far 一致）；被裁图元从快照里删掉（碰撞 pass 与 SVG 依赖一一对应，删了就错位）；用 `NaN` 占坑（全管道扫描的非有限数护栏会亮，且 `Math.min/max` 传染）。

依据：内核全跑 2469 条 BRAN、相机放在管子包围盒中心朝扫描方向（约半条管在相机背后）改前 / 改后各一趟：快照里相机背后顶点的镜像点 **146 279 → 0**（26 062 条布局 → 0），相机背后的数值文字却在屏内占位 **1795 → 0**，40 × 24 命中网格采样命中 **32 910 → 2312**（少掉的 93 % 打在幻影几何上），标签体与投影图元始终一一对应、非有限数 0；实机三条管相机站在弯管处朝管内看：镜像残留 0、pageerror 0、确定性 3 / 3。读数与文件见 `docs/verification/mbd-3d-dimension-presentation-2026-09-12/README.md`「二维快照按视锥裁剪」小节（`behind-camera-*.json/png`）。决策 d-496。落地：`kernel/geometry/sceneGeometry.ts`（`projectVertex` / `clipSceneSegment` / `clipPolyline` / `clipPolygon` / `CLIPPED_SCREEN_POINT` / `isClippedPrimitive`）、`kernel/layout/tagBillboard.ts`、`kernel/layout/occlusionPolicy.ts`、`export/svgOverlay.ts`、`kernel/types.ts`（`LayoutResult.primitives` 注释）。
