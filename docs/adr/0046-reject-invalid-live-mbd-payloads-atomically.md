# 外部 MBD JSON 按整包原子校验与替换

外部 MBD V2 JSON 必须先通过完整契约校验，再原子替换当前 MBD 外部图元；任一图元、问题项或顶层字段无效，或出现尚未纳入 V2 契约的图元类型时，整包拒绝、清空当前 MBD 来源并输出可定位诊断。不得保留旧数据，也不得静默显示部分有效图元，因为不完整尺寸图会让用户误判标注已经完整。parquet 通道仍可在转换为 V2 契约前逐行诊断和跳过，但进入统一适配层的负载同样必须完整有效。

被否决的替代：忽略无效图元并继续显示其余内容（可能形成无提示的工程信息缺失）、校验失败时保留上一 BRAN 数据（可能把旧尺寸误认为当前对象尺寸）。

依据：ADR 0043（MBD 数据只经冻结的 V2 契约形状进入适配层）、ADR 0028（外部尺寸只读）。
