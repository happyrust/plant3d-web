# 尺寸呈现内核采用纯布局函数加薄画家

新尺寸呈现内核不再让每个尺寸类型自持 Object3D 与几何更新逻辑，而是拆成两层：每个尺寸类型一个纯布局函数，输入规范化尺寸参数、相机与视口，输出与渲染库无关的图元列表（线段折线、V 形箭头线对、文字姿态框）；一个薄画家层把图元列表提交给 three.js 绘制并做资源复用。命中测试与拖拽热区对同一份图元列表计算屏幕距离，使视觉与拾取共享一份几何来源，这与 SolveSpace 同一段代码既绘制又算鼠标距离的做法同构。

该选择接受每帧重算布局的代价（SolveSpace 即为立即模式，尺寸数量级可控，画家层可做脏检查缓解），换取布局可无头单测、以 SolveSpace 行为为 golden 基准、以及画家可替换（未来出图 SVG/图纸复用同一布局）。
