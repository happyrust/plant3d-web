# 从零重建尺寸标注子系统

现有尺寸标注子系统将在新实现开始前整体删除，包括领域状态、绘制、交互、面板、持久化接线及 MBD 适配，以避免新架构继续继承旧子系统的耦合与接口形状。该选择接受重建期间尺寸功能不可用、失去可执行旧实现作为对照的代价；但旧 V5 `dimensions` 数据格式、迁移说明和固定样例必须保留，新系统需提供明确的数据迁移路径，删除旧代码不等于放弃历史用户数据。

边界澄清：「整体删除」只覆盖尺寸标注本体及其接线——尺寸标注类（线性/角度/径向/对齐）、尺寸面板、尺寸持久化接线、MBD 尺寸适配。被焊接、坡度、引线、测量可视化等非尺寸标注共用的呈现基建（AnnotationBase、AnnotationInteractionController、AnnotationMaterials 等）不在删除范围内，随非尺寸标注继续运行，直至后续阶段迁移到新呈现内核。新呈现内核在全新目录实现，禁止 import 旧尺寸子系统的任何代码。
