## 1. 做成了什么

底部状态栏多了一个常驻的「取最新」按钮。点一下，这个页面碰过的库（树上展开过的、装过模型的）对一次账：

- **模型树**刷新到位：新增的节点出现、删掉的消失、改名的换名字、挪走的到新位置；展开、勾选、选中留着，指向已不存在节点的记录清掉。
- **三维模型**刷新到位：后台已有新模型的节点重载（新增的构件装进来、删掉的撤下），库里已经没有的节点整个撤下。
  从树上点眼睛装的、整库显示（`show_dbnum`）装的、地址栏直装（`show_refno` / `debug_refno`）装的都管；整库显示里新出现的顶层 SITE 也装进来。
- **跟着模型走的**：属性面板的缓存失效重取；选中的构件被删了，登记成「已删除」（属性面板给现成的「该构件已删除」）；
  地址栏带 `mbd_refno` 时重取 MBD 标注；房间树在这一轮有变化时整棵重取。
- **一句交代**：树上增删改挪各几处、模型重载了几个节点、场景里多了 / 少了多少个构件、选中的是不是被删了、哪些库没跟到最新及原因。
  同一句进提示、状态栏（常驻，悬停看逐条细节）、控制台（逐条细节）。

边界照用户定的：只有这个手动按钮会触发；只把页面同步到后台现在已有的状态，不调用 `update/execute`、节点更新、生成这类让后端开工的接口；没有改后端；没有接任何自动触发。

**在真浏览器里验证过的场景**（这一轮都叠了模拟答复，见第 3 节，没有一个是真实增量；真实增量的回放见 `replay.md`）：

| 场景 | 结果 |
|---|---|
| 树：新增 2 个节点、删除 1 个、改名 1 个、挪位置 1 个 | 树上都跟上；回执逐项对 |
| 树的状态：展开的层、隐藏的构件、选中 | 留着；被删节点的记录清掉 |
| 眼睛装的 ZONE 下新增一台 / 删掉一台 | 新增的 7 件装进来，删掉的 4 件撤下 |
| 单独装过的节点被删 | 整个撤下，撤表 |
| 选中的构件被删 | 登记成已删除，属性面板显示「该构件已删除…」 |
| 后台没再变，再点一次 | 「已是最新」；不问节点状态、不重取记录 |
| 连点两下 | 第二下排队，先后跑完两轮，各给一句 |
| 后端「重启」之后记录查空 | 认出重启；场景一个构件都没撤；说明了原因 |
| 地址栏直装的根：多出 2 件 / 另一个根被删 | 2 件装进来；被删的根撤下 |
| 装一个大节点的同时点取最新 | 先等装载结束，装载没被打断，再对账 |
| 整库显示：已装 SITE 下新增 / 删除构件，新出现一个 SITE | 只重载有变化的那个 SITE（+7 −4）；新 SITE 装进来 |

**没做到的**见第 4 节。
