# 校审确认记录按模型版本分组查看

2026-10-08 开发验证；未部署，不作为业务验收签字。

## 已实现

- 混合版本的确认记录必须显式选择一组后再恢复，禁止自动猜测或合并不同版本坐标。两个校审面板共用选择，按任务及表单隔离。
- 以项目、模型库、单元根及精确 A/B 会话分组；节点、分屏方式、活动侧和差异筛选不拆成新组。同组按最新确认记录恢复查看方式。
- 两个面板均提供“确认记录版本”选择入口；批注、测量及保存比较基线使用所选组。切换后其他版本的已确认条目不再作为本机草稿叠加。
- 有未确认本机批注或测量时先拒绝切换，保持当前选择、模型和草稿，允许先保存或清除后重试。损坏的本机快照不猜测其内容。
- 混合组中的未绑定版本旧记录、无效版本记录不能合并回放。只有一组无版本旧记录仍兼容原行为，无法以此证明其模型版本或专业验收。
- 保存入口检查所选组与当前实际模型是否一致；未选择或模型尚未恢复时拒绝把结果合并确认。切换期间的迟到回执不能覆盖新组或错误提示。
- 净距恢复校验几何版本，允许同一模型版本上的不同查看方式；保存回执仍检查完整快照。
