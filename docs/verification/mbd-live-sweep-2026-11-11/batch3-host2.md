## 2. 改了什么

**票 32 的另一半**：土建楼板旁的墙也照 PML L1823 不收 SITE 名以 `/MDS` 开头、没有 SITE 的墙（`floor_wall_site_passes` 对建筑、土建两种模式

**票 28**：EM4 按名字一个管道附件都没取到（支架没有名字也算）时，退到 REST 下 HANG 的 HREF 所指的 ATTA——HANG 的文件原序、同一个只取一次，

`adapter.support_pipe_atta_by_href`，点名认了哪几个 ATTA（例：「没有名字以支架名 /1WCC-R330.016 开头的管道附件（PML 只按名字找，
matchwild(name, suppname + '*')），改按 HANG 的 HREF 认了 1 个 ATTA：/R330.016A。管道信息、中心标识与找墙都按它们出；PML 在没有管道附件

放宽，裁决内容写在 `.scratch\mbd-impl\status\host2.md`，请 solver2 登记（核对程度：读代码推断）。
- 无名的 EM4 支架（票上要确认的一条）：AMS 133 个，HANG 都没有指着 ATTA，放宽对它们生效但没有一个变（核对过数据）。
- 按名字找到附件、HREF 另指名字不合约定的 ATTA 的 25 个支架：不动（用例守着 `24383_69823`）。

**判型缺省表注释**：去掉在 #103 里查不到的「决定」，改成事实——缺省表比 getmbdtype 宽（getmbdtype 只把 SITE 名含 INST / PIPE 的站点里的 BRAN
