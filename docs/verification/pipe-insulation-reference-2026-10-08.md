# D13 管道信息：保温规格选取与含保温外径参考开发验证（2026-10-08）

本轮在 [标高参考值](pipe-elevation-reference-2026-10-08.md) 的基础上，核对保温规格能否读出厚度，并补含保温外径参考值。业务包络是否含保温、保温目录参数的含义都待专业确认，本轮数值只作参考；D13 仍进行中，未部署，未做专业/ISO 核对和签字。

## 核对结论

保温规格可以沿 E3D 的选择规则读到目录参数，但参数含义不能从数据本身确定：

- 选取链：段的 ISPE → 保温 SPEC（`QUES TYPE`）→ `TANS INSU` 的 SELE（`QUES TEMP`）→ 温度范围行（ANSW..MAXA，`QUES PBOR`）→ 通径范围的 SPCO → CATR 指向的 GTYP INSU 目录件 → PARA[1]。温度取 BRAN 的 TEMP，通径取该段的到达通径。
- 24381/145018：SPEC `/INS_BR340_XXX`，TEMP 360 落在 340–1000 行，通径 100 落在 40–100 行 `/FRA/INS/BR340_XXX/110A`，目录件 `/A1/INS10` 的 PARA[1] = 200。
- 同一温度行的 5 个通径档：50A→INS5（PARA 100）、60A→INS6（120）、90A→INS9（180）、110A→INS10（200）、170A→INS17（340）。除 110A 外都满足“PARA[1] = 2 × 规格名数字”，即更像直径增量（厚度 50/60/90/170 mm）；110A 行指向 INS10 而不是 INS11，与命名规律不符，需核对目录。E3D 文档只说明主件可经 IPARAM 引用保温件参数，PARA[1] 的含义由目录几何决定。

## 实现

- 每段的 ISPE：成员取自身 ISPE，隐式直管取 BRAN（首段）或上游成员的 ISPE；未设置即为无保温。按 E3D 选择规则逐级匹配，同一（规格、温度、通径）只读一次；目录各级会话与中心线会话核对，不一致标待核实。
- 新字段“保温参数”（PARA[1] 及覆盖段数，标“含义待确认”）和“含保温外径参考”（外径 + PARA[1] 视为直径增量，外径 + 2×PARA[1] 视为厚度，两种都列出），均为待确认；整根管都没有保温规格时不显示这两个字段。面板新增“保温选取及来源”，逐段列出通径、参数和完整选取链，并随上下文快照保存。
- 无法匹配温度或通径、规格行未挂目录件、目录件不是 INSU 或缺 PARA[1]、接口失败时，该段明确标“缺失/待核实”并写明原因，不给数值。
