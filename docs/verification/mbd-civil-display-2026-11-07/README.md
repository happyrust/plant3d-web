## 观察

- 1112 的土建墙板读起来就是结构图：墙面上的孔洞尺寸与定位、标高、厚度圈按 LOD 由远到近逐级出现（`off/17496_118364/mid.png`）。
- 建筑楼板首轮的问题：房间号、`80 / -20` 建筑标高与圈散落在楼板以外。原因在 PML `getrooms`（`markCivil.pmlobj:2104`）按楼板的轴对齐包围盒收房间、只比标高，弧形板把邻板的房间也编上号，整层显示时一个房间会被几块板重复编号。求解器加了板顶轮廓过滤（D-CIVIL-017），`24381_38614` 从 221 个图元降到 109、缺省呈现重叠从 126–189 对降到 2–3 对（`off/24381_38614/near.png`）。
- 墙名高出板面一个墙高：PML `drawarchname` 把墙名写在墙顶中心（L1954-2016），斜视时看上去离板很远，与 PML 一致。
- 待查：`24381_38614` 剩下的两个房间号里，`R230`（-520, -17660）在近景里落在弧形板的弧边外。正在核对板顶轮廓的圆弧口径（宿主给的 FRADIUS 与网格 `flatten_ring` / 求解器 `profile_from_vertices` 是否一致），结论出来后重拍。
- 大楼板 `24381_38695` 一屏几百个标签：墙名、房间号是主档常显，建筑标高是次档（缺省主题次档门槛为 0），远景必然拥挤；中、近景仍有 90–101 对。这是整块 40 m 楼板一次出图的密度，放大看局部时清楚。
