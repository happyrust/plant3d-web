# 构件、管间与 BRAN 结构净距本机保存（开发阶段）

## 实现

已有 `useClearanceStore` 的构件→墙拾取和空间查询抽屉的构件→构件记录现在自动写入本机存储。Viewer 绑定的作用域包含项目、库、用户、批注任务/轮次、单据、流程节点以及当前 A/B 会话和单元范围。未知项目只保留内存状态。

恢复时验证格式、所属作用域、记录标识、有限距离与端点。保留结果快照、两侧模型会话号、隐藏状态与标注开关，统一标为 `stale` 并提示重算。保存失败显式提示并在本次应用进程内保留该作用域的未落盘快照；重新切回可重试保存。损坏或错位的存储原文不会被自动覆盖。抽屉提供重算、隐藏/显示和移除入口。

清空、作用域切换、退出 Viewer 和进入历史对比会使旧请求失效；同一对构件较旧响应不能覆盖较新响应。并发时“计算中”直到当前上下文的在途请求全部结束。历史对比期间不能以当前模型接口产生历史净距。重算失败时保留旧快照，三维文字显示“重算失败，旧值”。

“本机已保存”明确注明“未提交校审”。这不是云端校审保存，也不是专业验收。

管间批量和 BRAN 结构候选现已接入同一 Viewer 上下文作用域。管间保存世界毫米端点、模型会话、选中管道和显示筛选；BRAN 保存候选、类型筛选、绘制选择和精度来源，重开统一标记过期。损坏原文不会被覆盖，配额失败可切回并重试。进入历史模式使在途查询失效，并禁止当前模型精算及交互估算。管间三维标注修正为世界毫米→设计米，定位使用当前模型矩阵，避免重开后的场景偏移。
