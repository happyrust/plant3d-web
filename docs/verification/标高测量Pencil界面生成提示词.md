# 标高测量 Pencil 界面生成提示词

> 适用范围：`plant3d-web` 三维 viewer 测量工具界面。
> 目标：用 Pencil 生成 `点标高` 与 `高差` 测量的交互 UI 设计稿。
> 建议设计源：`ui/三维校审/review-reviewer.pen`；若不想改现有设计稿，可新建 `ui/测量/elevation-measurement.pen`。
> 当前日期：2026-04-24。

---

## 一、给 Pencil 的主提示词

```text
请为 plant3d-web 的三维校审 reviewer 工作台生成一组“标高测量”交互 UI 设计稿。

产品背景：
- 这是一个工业三维模型校审系统，核心区域是 xeokit 三维 viewer。
- 用户在 viewer 中进行测量，测量结果会作为校审证据进入确认记录。
- 现有测量工具已有“距离测量”和“角度测量”，现在新增“点标高”和“高差”。
- 设计风格应贴合工程软件工作台：信息密度适中、清晰、克制、可长期操作，不做营销页、插画页或大面积装饰。

界面范围：
请生成以下 8 个 frame：
1. Measurement Panel / Idle
2. Measurement Panel / Settings
3. Measurement Panel / List
4. Viewer / Left Measure Menu
5. Viewer / Overlay / 点标高
6. Viewer / Overlay / 高差
7. Review / Create Measurement Menu
8. Designer Comment / Evidence Menu

全局布局：
- 画布模拟三维 viewer 工作台，主视图区在左侧或中间，右侧保留测量面板。
- 颜色遵循现有 plant3d-web 工具面板风格：白色/浅灰面板、细边框、蓝色主操作、橙色提示、绿色成功状态。
- 所有按钮使用紧凑型工程软件尺寸，不使用夸张圆角；面板圆角不超过 8px。
- 文案必须使用简体中文。
- 数值示例统一使用米：`+12.350m`、`+1.250m`、`+3.250m`。

Frame 1：Measurement Panel / Idle
- 顶部保留“工具状态”卡片。
- 操作按钮顺序固定为：`关闭`、`距离`、`点标高`、`高差`、`角度`。
- `点标高` 和 `高差` 应与现有 `距离`、`角度`同级，不要放到二级菜单。
- 新增“标高基准”设置条，包含：
  - 标签：`标高基准`
  - 数值输入框：默认 `0.000`
  - 单位尾缀：`m`
  - 次级按钮：`恢复 0`
- 状态提示：`选择测量工具后，在三维视图中拾取点位。`

Frame 2：Measurement Panel / Settings
- 保留已有测量样式区域。
- 新增“点标高”样式组，包含 4 个开关：
  - `显示绝对标高`
  - `显示相对基准`
  - `显示点标记`
  - `显示引线`
- 新增“高差”样式组，包含 4 个开关：
  - `显示起终点标高`
  - `显示高差标签`
  - `显示竖向辅助线`
  - `显示端点`
- 所有开关默认打开。
- 标高基准应在样式设置区域可见，体现 datum 会影响相对基准与高差显示。

Frame 3：Measurement Panel / List
- 列表中展示 4 类 badge：`距离`、`点标高`、`高差`、`角度`。
- 点标高卡片示例：
  - badge：`点标高`
  - 标题：`标高点 01`
  - 副文案：`绝对 +12.350m · 相对基准 +1.250m`
  - 操作：定位、隐藏、删除
- 高差卡片示例：
  - badge：`高差`
  - 标题：`高差 01`
  - 副文案：`起点 +12.350m · 终点 +15.600m · 高差 +3.250m`
  - 操作：定位、隐藏、删除
- 列表底部保留 `清空全部`。

Frame 4：Viewer / Left Measure Menu
- 左侧 viewer 工具栏展开测量下拉菜单。
- 菜单顺序固定为：
  - `长度测量`
  - `点标高`
  - `高差`
  - `角度测量`
  - `构件最近点`
  - `管-墙/柱`
  - `管-管`
- `点标高` 图标可使用定位点/垂直标高含义。
- `高差` 图标可使用上下箭头/竖向尺寸含义。

Frame 5：Viewer / Overlay / 点标高
- viewer 中展示一个被拾取的点。
- 点位上方画一根短竖引线，连接到 pill 标签。
- 标签两行：
  - 第一行：`标高 +12.350m`
  - 第二行：`相对基准 +1.250m`
- 显示 hover pointer lens：
  - 未命中时文案：`等待可拾取点`
  - 命中时文案：`锁定标高点`
- 体现交互规则：单击一点即完成测量。
- 标签要靠近点位，但不要遮挡主要构件。

Frame 6：Viewer / Overlay / 高差
- viewer 中展示两个点：起点与终点。
- 起点和终点之间画竖向辅助线，辅助线中心显示 pill 标签：`高差 +3.250m`。
- 起点小标签：`起 +12.350m`。
- 终点小标签：`终 +15.600m`。
- 第二点 hover 阶段显示预览态，线条可用虚线或半透明。
- pointer lens 文案：
  - 第一阶段：`锁定起点`
  - 第二阶段：`更新终点`
- 体现交互规则：第一击锁定起点，第二击完成高差。

Frame 7：Review / Create Measurement Menu
- 在 reviewer 工作台右侧“批注与测量”区域展示 `+测量` 菜单。
- 菜单项包含：
  - `距离测量`
  - `点标高`
  - `高差`
  - `角度测量`
- `点标高` 说明文案：`单击一点完成标高测量`。
- `高差` 说明文案：`选择两点完成高差测量`。
- 菜单应紧贴当前工作台风格，不要做成大型弹窗。

Frame 8：Designer Comment / Evidence Menu
- 在设计人处理批注面板中展示“补充测量证据”区域。
- 增加两个操作按钮：
  - `新增点标高`
  - `新增高差`
- 点击后的 toast 文案分别为：
  - `单击一点完成标高测量`
  - `选择两点完成高差测量`
- 已关联测量证据列表中能显示：
  - `点标高 · 绝对 +12.350m · 相对基准 +1.250m`
  - `高差 · 起点 +12.350m · 终点 +15.600m · 高差 +3.250m`

交互状态要求：
- 点标高进入模式后，hover 即预览当前点标高，单击命中面后生成记录。
- 点标高点击空白或退出模式时取消草稿。
- 高差第一击锁定起点，第二点 hover 实时预览，高差第二击完成。
- 高差第二阶段点击空白时取消整条草稿。
- datum 变更后，已有点标高/高差记录的相对值应表现为即时刷新。
- 现有定位、隐藏、删除、清空全部、打开测量面板操作对四类测量一致。

视觉细节：
- 点标高使用蓝色点标记和蓝色标签。
- 高差使用绿色或青色竖向辅助线，中心高差标签更醒目。
- 草稿/hover 状态使用半透明线条和虚线。
- 完成态使用实线和更高对比度标签。
- 不要使用大面积渐变背景、插画背景、营销卡片或过度装饰。
```

## 二、Pencil 生成后检查清单

- `Measurement Panel / Idle` 中按钮顺序必须是：`关闭`、`距离`、`点标高`、`高差`、`角度`。
- `标高基准` 必须是全局设置，不画成单条测量记录的局部字段。
- `点标高` 必须同时展示 `绝对标高` 与 `相对基准`。
- `高差` 必须同时展示 `起点标高`、`终点标高`、`高差`。
- `Viewer / Left Measure Menu` 中 `点标高` 与 `高差` 必须位于 `长度测量` 和 `角度测量` 之间。
- `Review / Create Measurement Menu` 与 `Designer Comment / Evidence Menu` 都必须出现新入口。
- 所有文案必须为简体中文。
- 标签、按钮、菜单不得遮挡三维模型核心区域。

## 三、面向实现对齐的字段口径

| UI 名称 | 命令 ID | 工具模式 | 测量 kind |
| --- | --- | --- | --- |
| 点标高 | `measurement.elevation_point` | `xeokit_measure_elevation_point` | `elevation_point` |
| 高差 | `measurement.elevation_delta` | `xeokit_measure_elevation_delta` | `elevation_delta` |

| 字段 | 说明 |
| --- | --- |
| `absoluteElevation` | 绝对标高，取 `worldPos.z` |
| `datumElevation` | 标高基准，默认 `0` |
| `relativeElevation` | 相对基准标高，等于 `worldPos.z - datumElevation` |
| `originElevation` | 高差起点标高 |
| `targetElevation` | 高差终点标高 |
| `deltaElevation` | 高差，等于 `targetElevation - originElevation` |

## 四、可选补充提示词

若 Pencil 首轮生成结果过于装饰化，可追加：

```text
请降低装饰感，改成工业工程软件风格。减少大卡片、渐变、插画和留白。提高信息密度，保留清晰边框、紧凑按钮、可扫描的测量列表。三维 viewer 是主角，测量标签和菜单只作为操作覆盖层。
```

若 Pencil 忽略高差预览态，可追加：

```text
请补充“高差第二点 hover 预览”状态。第一点为已锁定实心点，第二点为半透明预览点，二者之间的竖向辅助线为虚线，中心标签实时显示 `高差 +3.250m`。
```

若 Pencil 忽略 review 证据链，可追加：

```text
请补充 reviewer 工作台与设计人批注处理面板中的测量证据入口。测量不是独立流程状态，而是随“确认当前数据”一起保存和回放的校审证据。
```
