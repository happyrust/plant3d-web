## 观察

- **外移的标签连引线回锚点**（75160d04）：首轮截图里 `24381_38614` 的房间号 `R230` / `R263` 和它们的标高药丸落在弧形楼板外。房间点本身在板上
  （plant-mbd 448b25c 已用两条单测钉住 FRADIUS 口径），标签也在板顶标高（z = 90 mm），是三维呈现的避让把这些没有引线目标的标签挪到了外圈候选位、
  又没有引线。现在挪离自己位置的标签从锚点连一条引线到最近的体边，`off/24381_38614/near.png` 里每个房间号、标高药丸都指回自己的点；
  40 m 楼板 `24381_38695` 近景里每组房间号 / 标高从房间点放射出去。摆位与重叠统计不变。
- 平贴呈现是调试呈现：管道在短直段密集处仍拥挤（文字被钳到最小可读字号后超过 PML 的世界尺度间隙），缺省呈现不受影响。
- 验收脚本偶发一次取景过早：首跑时 `24381_44303` 平贴的远景相机还停在视图缺省位（4, 3, 4），重叠 21 / 6 / 9；单独重跑两次都稳定为 7 / 4 / 3，
  这里放的是重跑结果。脚本的「相机停稳」判据在飞行动画开始之前也会成立，是脚本自身的问题。
