## 2. 角色与主链说明

仿 PMS 当前按 `external` 外部流程驱动理解：

- `SJ`：发起编校审，并执行送审 `active`
- `JH`：校核，同意 `agree`
- `SH`：审核，同意 `agree`
- `PZ`：批准，同意 `agree` 或退回 `return`

在此模式下，真正的流转动作由仿 PMS 壳执行，三维页面负责：

- 创建批注和截图
- 保存批注/测量/附件证据
- 展示批注工作区、表格和处理时间线
- 按当前节点恢复只读或可处理状态

## 3. 人工操作教程

### 3.1 SJ 发起编校审

1. 打开仿 PMS 调试页。
2. 选择或保持 `SJ` 角色。
3. 点击新增/发起编校审。
4. 在三维页面中选择模型对象，默认测试可使用 `BRAN 24381_145018`。
5. 填写包名、校核人、审核人等信息。
6. 提交编校审单。
7. 回到仿 PMS 壳，执行 `active`。

期望结果：

- 后端生成 `form_id` 和 `task_id`。
- 单据从 `sj/draft` 推进到 `jd/submitted`。

### 3.2 JH 打开并处理

1. 切换到 `JH` 角色。
2. 打开同一张三维校审单。
3. 在三维页面进入批注工作区。
4. 创建云线批注或选择已有批注。
5. 设置错误类型：
   - 原则错误
   - 一般错误
   - 图面错误
6. 对云线批注点击“添加截图 · 记录当前视角”。
7. 截图上传时观察进度条。
8. 如已有截图，点击“重拍”会弹出确认，确认后新图替换旧图。
9. 在批注工作区、批注表格、处理时间线中检查缩略图。
10. 保存新增证据或提交处理意见。
11. 回到仿 PMS 壳，执行 `agree`。

期望结果：

- 批注记录中写入 `screenshot.url`。
- cloud 旧字段 `thumbnailUrl` 同步可用。
- 附件上传请求携带 `sourceAnnotationId`、`description`、`type=annotation_screenshot`。
- JH `agree` 后流程推进到 `SH`。

### 3.3 SH 审核

1. 切换到 `SH` 角色。
2. 打开同一张三维校审单。
3. 在批注表格或工作区查看 JH 阶段保存的批注截图。
4. 确认处理意见。
5. 回到仿 PMS 壳，执行 `agree`。

期望结果：

- 截图缩略图仍可展示。
- 流程推进到 `PZ`。

### 3.4 PZ 批准通过

1. 切换到 `PZ` 角色。
2. 打开同一张三维校审单。
3. 检查批注、截图和处理记录。
4. 执行 `agree`。

期望结果：

- 单据进入 `approved`。
- 重新打开后进入只读态。

### 3.5 PZ 退回 SJ

1. 按 `SJ -> JH -> SH` 推进到 `PZ`。
2. 在 `PZ` 节点执行 `return`。
3. 切回 `SJ` 角色并重新打开单据。

期望结果：

- 后端当前节点回到 `sj`。
- 单据状态为 `draft`。
- 设计侧进入发起/处理入口，而不是只读页。

## 5. 操作注意事项

1. 仿 PMS 主链应以外部流程按钮为准，不要把三维页面内部按钮当作正式流转入口。
2. 截图属于批注证据，先保存批注/证据，再执行外部 `agree` / `return`。
3. 已有截图重拍会替换旧图，并异步删除旧附件；若删除失败，只会 toast 警告。
4. 如果嵌入页跨域导致 Playwright 无法注入，应改为同源新标签或调整模拟器嵌入方式。
5. localStorage 离线截图兜底尚未实现，不要把离线截图作为当前验收项。
