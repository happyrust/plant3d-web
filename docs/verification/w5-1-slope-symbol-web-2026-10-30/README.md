## 图上可见的坡度符号形态

红色箭头对：`SLOPE_ARROW_LENGTH_RATIO = 0.08`（翼长 = 0.08 × 字高）、
半张角 20°，沿 slope 线的 start→end 方向（`mbdV2ExternalAnnotations.ts:65-66`、
`:229-251`、`:1057-1071`）。`mid.png` 里最清晰——`24383_75125` 的
R520/R510 弯管段与 `24381_105733` 的竖管段，每个坡度变换点一对红箭头，
`near.png` 能看到箭头与红色坡度线相连。

**没有三角形**：Web 侧走描边通道（`SceneLine`），实心三角通道
（`makeFilledSceneArrow` → `scene-triangle`）完全没用上——这是 §11.8 的
关键事实，图上是它的视觉证据。
