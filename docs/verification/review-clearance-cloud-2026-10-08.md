# 三类净距云端快照：前后端开发验证

日期：2026-10-08。此记录属于开发验证，不是业务验收或部署记录。

## 已实现

- 校审记录接收、保存并读回 `clearanceSnapshot`，包含构件净距、管间净距和 BRAN 查询结果、显示选择及计算来源。
- 快照绑定项目、任务、表单与精确模型上下文；换上下文不能沿用原快照。校验单位、参考号、重复结果、坐标、距离和容量。
- 构件坐标采用设计世界米，管间及 BRAN 采用 E3D 世界毫米；管间端点必须与设计端点一致，拒绝把场景坐标存为设计坐标。
- 快照进入整条记录摘要及现有修订并发保护；工作流投影保留快照。未携带快照的旧客户端兼容原行为。
- 实际数据库读回测试发现嵌套 JSON 空值被省略，改为保存 JSON 文本、接口读回对象，保留空选择和空模型对比字段；兼容原对象列。
- 前端查看器提供脱离实时对象的快照，校审保存、PMS 流转前自动保存、脏数据检测和提交阻断均包含三类结果。保存回执未完整返回快照时拒绝确认成功。
- 重开先恢复并核对模型上下文，再预检三类结果，全部校验成功后同步替换；损坏快照不清本机草稿。恢复结果标记待重算，模型上下文相同不代表专业验收通过。
- 本机有不同结果时拒绝覆盖并显示冲突；保留草稿供用户先保存或清除后重试。快照内容进入回放标识，无修订号的旧记录变化也重新回放。恢复期间取消旧计算，防止迟到结果覆盖。
