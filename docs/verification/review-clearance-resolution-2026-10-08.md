# 校审净距本机与云端冲突处置

2026-10-08 开发验证；未部署，不作为业务验收签字。

两个校审面板提供三类净距的本机/云端条数及最近距离比较。可保留本机，或先备份本机再恢复云端；支持撤销本次恢复及下载本机 JSON 备份。备份按用户、任务、节点及模型版本的本机存储上下文隔离。保存成功后才清除保留本机提示。

处理选择绑定任务、表单、节点、用户、模型版本和当前快照摘要。比较后本机结果改变时旧选择失效，重新比较；任务或模型切换后不能应用旧选择。云端快照先完整校验，备份写入失败时停止恢复。恢复云端后再修改本机结果时禁止撤销覆盖新修改，保留下载备份入口。
