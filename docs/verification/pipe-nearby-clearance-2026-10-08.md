# D12 周边管道净距与有限管段开发验证（2026-10-08）

本轮已补单根 BRAN 的周边批量入口、候选归属归并及当前投影直管段补集。仍为开发验证，未部署，不能替代真实 E3D/ISO 专业验收。最终参考值的绝对允许误差为 10 mm；实体外表面、保温或包络的业务口径与签字负责人仍待确认。

## 实现与发现

- 新增 `GET /api/v1/spatial/nearby/branches`。查询以整根模型的边界为源，按盒间距离取保守候选，避免长管道端部邻居因离中心点过远而遗漏。最终数值仍由生产三角网格表面算法计算。
- 只读旧接口探查：`24381/145018`、500 mm，过滤 BRAN 返回 0；不加 noun 过滤返回 1101 条（UNSET 1095、WELD 3、WALL 2、VALV 1）。因此不沿用直接过滤索引 noun 的方案；读取权威 TYPE 和属主链归并到最近 BRAN，独立于交付单元配置。
- 隐式直管段按 ADR-072 不进入普通空间树；新接口补扫当前 BRAN 投影中的有效网格边界，排除历史投影、负实体和无效直管段。未知归属、损坏边界或空间候选截断均声明覆盖不完整。
- 按距离/refno 稳定排序、分页；前端逐页归并去重，拒绝集合总数变化或无进展分页。查找期间切换选择、模型上下文或检测范围不会套用迟到结果。已有四并发净距查询复用最大距离，含交叉/斜交。
- 保留原结果的失败/空集合处理；覆盖不完整显式提示。旧辅助算法不再虚构 229 mm 外径。有限表面计算修复恰好等于 max_distance 的命中被剪枝问题。

## 证据和边界

- 前端完整回归：338 文件、3152 项通过；构建通过，类型基线 499，新增错误 0；本轮文件规范检查 0 错误。
- Chrome 实际抽屉与 store、DTX 开发模型：100/500 mm 两条结果、截断提示、503 保留、空集合保留，页面异常 0。空间与净距 HTTP 响应为受控 fixture，不能据此声称真实候选接口已联调。
- 后端同一 `pipe_clearance_probe` 可执行例调用生产候选归并及表面算法。候选检查覆盖成员去重、自身排除、仅投影管段、长根端部、远根排除、历史排除、无效直管段排除、分页、未知归属/无效边界提示。
- 128 边闭合有限圆柱解析参考：平行 50、交叉 50、斜交 50、端面间隔 30、接触 0、交叉穿透 0、大坐标斜交 50、上限边界 500 mm。8 例正反顺序均通过，本组实际误差 0 mm，距离与端点一致性校验 ≤0.1 mm。样例不是现场专业数据，也未覆盖所有实体曲面。
- 候选逻辑及例程序已通过编译运行；新路由复用既有身份校验与空间树就绪门禁。真实模型的新路由 HTTP、性能、持久化重开及专业参考复核仍须执行。
- 既有空间查询回归 27 项通过；表面内核既有回归 23 项通过、1 项原有忽略。没有用这些开发检查填写最终专业验收通过。

## 下一步及通过标准

1. 将新接口与前端在联调环境同时构建，执行至少 3 组真实典型管道及对应 ISO；包含长根端部、管件＋直段、跨库和大量分页。记录候选覆盖、耗时、模型会话、真实响应、显示端点、反向与重复生成去重、显隐和重开结果。
2. 确认表面口径后逐个对照专业参考值，绝对差 ≤10 mm；缺外径不得冒充精确净距。失败登记缺陷，修复后同样例复测并回归相关量距项，专业负责人签字后才能把 D12 改为通过。
