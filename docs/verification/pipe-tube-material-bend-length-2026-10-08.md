# D13 管道信息：隐式直管材质与含弯头弧长管长开发验证（2026-10-08）

本轮在 [版本核对与成员材质](pipe-version-material-2026-10-08.md) 的基础上补两项：隐式直管的材质来源，以及含弯头弧长的管长参考值。D13 仍进行中；未部署，未做专业/ISO 核对和签字。完整管长口径尚待专业确认，本轮数值只作参考。

## 实现

- 隐式直管（中心线 `from~to` 段）：首段 `Head~…` 取 BRAN 的 HSTU，其余取上游成员的 LSTU，再走同一规格链 `SPCO.MATX → SMTE.XTEX`，逐级写明会话；版本规则与成员相同，不读 BRAN/PIPE 的 MATN/MATR。成员材质列表按中心线顺序包含成员和隐式直管，卡片计数单位改为“段”。
- 弯头弧长：对 BEND/ELBO 读取成员自身 ANGL（与中心线同会话），用中心线两端口间直线距离 c 推算半径 R = c / (2·sin(θ/2))，弧长 = R·θ。新字段“管长（含弯头）”= 直管段总长 + 弧长之和，状态固定为待确认；任一弯头缺少角度或端口时该字段不出值并给出警告。原“直管段总长”不变。面板新增“弯头弧长及来源”，逐件列出角度、端口弦长、弧长、推算半径和来源，并随上下文快照保存。
- 推算假定端口位于弧的两端（标准对焊弯头和管道弯管符合）；带直段延长的弯头会算大，需专业复核。
