三维校审完整流程

当前主线是外部平台驱动：PMS 或仿 PMS 负责发起和流程动作，plant3d-web 负责三维数据保存、上下文恢复、批注处理、测量、附件和留痕展示。 form_id 是跨系统单据锚点，task_id 是平台内部任务锚点。

第一锚点

form_id 串起 PMS、仿 PMS、嵌入页、任务恢复和 workflow 查询。排障优先查它。

流程边界

默认外部驱动。plant3d-web 保存和恢复三维校审数据，真正流转由 workflow/verify → workflow/sync 完成。

驳回语义

驳回后不是重填表单，而是处理全部批注、确认当前数据，再重新发起并继续流转。
