# D13 管道信息：中心线/管顶/管底标高参考值开发验证（2026-10-08）

本轮在 [隐式直管材质与含弯头弧长管长](pipe-tube-material-bend-length-2026-10-08.md) 的基础上补标高参考值。业务标高取轴线、管顶还是管底仍待专业确认，本轮数值只作参考；D13 仍进行中，未部署，未做专业/ISO 核对和签字。

## 实现

- “中心线标高范围”：全部中心线端点（含管件端口）的 E3D 世界 Z 最小值至最大值，状态为派生。
- “管顶/管底标高”：只用直管段（隐式直管和 TUBI/FTUB）。每段管顶 = 两端中心线 Z 的较大值 + 外径/2 × √(1 − dz²)，管底 = 较小值 − 同一偏移，dz 为轴向的竖直分量：水平段偏移为半径，竖直段为 0，倾斜段介于两者之间。外径取该段的目录/估算值，缺外径的段不出值并计入覆盖数；管件实体外形不计入。状态固定为待确认。
- 面板新增“直管段标高”，逐段列出水平/竖直/倾斜、两端中心线 Z、管顶、管底和外径，并随上下文快照保存。原“标注锚点标高”不变。
