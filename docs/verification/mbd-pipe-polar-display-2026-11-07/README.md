## 结果（新口径）

| 管道 | 绘制（远 / 中 / 近）`off` | 重叠对 `off` | `flat` |
|---|---|---|---|
| `24381_145018` | 83 / 86 / 91 | 2 / 0 / 2 | 114 / 36 / 13 |
| `24383_91813`（竖管） | 9 / 9 / 9 | 0 / 0 / 0 | 0 / 0 / 0 |
| `24383_99996` | 54 / 59 / 59 | 1 / 1 / 0 | 43 / 27 / 18 |

- 缺省呈现三条管道基本零重叠：尺寸沿管、标高药丸、连接坐标卡片、元件名框互不相压，流向箭头是尺寸线上的小红箭头（`off/24381_145018/mid.png`）。
- 竖管 `24383_91813` 原先缺省呈现有 11–15 对、平贴 17–19 对，全部是五组安装角度各自的角度字与两条方向小字互压：PML 按文字长取弧半径（几毫米），三条字只在接近真实尺度时分得开，远处被放大到可读字号后挤成一团，组内互压不触发整组避让。安装角度整组（`angle_dim` + `:dirtext1/2`）改进细节档后归零，放大到够近才出现；斜管辅助与坡度原本就是细节档，设备 / 土建的偏转角度按 function 同为细节档。
- 平贴呈现在 `24381_145018` 这种短直段密集的管道上仍然拥挤：文字按极坐标选出的朝向沿管排，平贴文字被钳到最小可读字号后超过 PML 按世界尺度留的空隙；近景降到 13 对。缺省呈现不受影响。
- 管道的新宿主字段（构件包围盒、真外径、P 点 bore、墙体定位墙面、M2b 的流向 / 伴热 / 连接 / 目录原语等）还在 gen-model 的管道通道里，接上后重拍。
