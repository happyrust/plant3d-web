# 三维校审：云线与模型元素绑定使用教程

## 适用环境

- 测试站点：<http://123.57.182.243/?show_dbnum=7997&output_project=AvevaMarineSample>
- 测试模型库：`7997`
- 示例元素：BRAN `24381_145018`
- 示例名称：`/Copy-of-RCS0014-1R43012新`

## 一、创建云线并绑定模型元素

1. 打开测试站点，等待三维模型加载完成。
2. 点击顶部 **校审**，选择 **校审面板**。
3. 在模型树或三维视口中选择需要关联的模型元素。
4. 在右侧 **批注与测量** 中点击 **云线批注**。
5. 在视口顶部的 **关联元素** 区域选择目标来源：
   - **使用当前选择**：使用模型树或视口中已经选中的元素。
   - **点选目标**：在三维视口中连续点选，按 Enter 确认。
   - **框选目标**：在三维视口中框选多个元素。
6. 检查目标标签中的 RefNo。误选时点击标签右侧删除按钮，也可以点击 **清空** 后重新选择。
7. 点击三维模型，为云线选择锚点。
8. 在三维视口中拖拽绘制云线。
9. 填写批注标题、问题说明和错误类型，点击 **保存批注**。

> 新建云线至少需要一个关联元素。修改关联元素后，系统会清除旧锚点，需要重新点击模型选择锚点。

## 二、一对一和一对多绑定

### 一对一

1. 只选择一个模型元素。
2. 点击 **使用当前选择**。
3. 确认标题显示 **关联元素 1**，并检查目标 RefNo。

### 一对多

1. 在模型树中按住 Ctrl 选择多个元素，或使用 **点选目标**、**框选目标**。
2. 点击 **使用当前选择**，或按 Enter 确认点选结果。
3. 确认 **关联元素 N** 与目标标签数量一致。
4. 删除误选标签后再绘制，保存结果只包含最终目标列表。

同一个 RefNo 可以同时作为目标元素和云线锚点。系统分别保存 `member` 和 `anchor` 角色，定位目标时不会重复高亮。

## 三、查看截图和重拍

1. 保存并确认批注后，系统自动保存当前三维视角的 PNG 截图。
2. 打开批注详情，在截图区域查看自动截图。
3. 如需更新视角，调整相机后点击 **重拍**。
4. 重拍只更新截图，不修改云线与模型元素的绑定关系。

## 四、从云线查找模型元素

1. 打开 **校审面板**，进入云线批注详情。
2. 在 **关联元素** 区域查看目标数量、Noun 和 RefNo。
3. 点击某个元素的 **定位高亮**：
   - 加载该元素；
   - 清除上一组选择；
   - 聚焦并高亮该元素。
4. 点击 **定位高亮全部**：
   - 加载所有可用目标；
   - 对成功加载的目标执行一次合并聚焦；
   - 同时高亮全部目标。

如果部分元素加载失败，系统保留并高亮成功项，同时提示失败数量；全部失败时不改变原视角和原选择。

## 五、从模型元素查找云线

1. 在模型树或三维视口中选择一个模型元素。
2. 打开该元素的关联批注入口。
3. 在 **关联云线** 列表中查看绑定到该元素的所有云线。
4. 点击云线记录，打开对应批注详情并显示云线。
5. 多选模型元素时，列表合并展示命中任一元素的云线，并按云线 ID 去重。

## 六、取消和退出

- 点选或框选时按 Esc：返回云线模式，保留已经确认的目标。
- 云线模式按 Esc：退出本次创建并清空目标、锚点和预览。
- 切换到其他批注工具：清空当前云线创建状态。
- 创建成功：清空本次目标和锚点，但保留云线工具，便于继续创建下一条。

## 七、常见问题

### 页面一直显示“等待模型加载完成”

先检查以下接口：

```text
/files/output/AvevaMarineSample/parquet/manifest_7997_buckets.json
/api/model/parquet-version/7997
```

如果接口返回 502，模型锚点、云线绘制和定位高亮都无法验证。恢复模型数据服务后刷新页面，再重新执行绑定流程。

### “使用当前选择”后仍显示 0 个元素

1. 退出当前点选或框选状态。
2. 在模型树或视口中重新选择元素。
3. 确认元素已加载并处于选中高亮状态。
4. 再次点击 **使用当前选择**。

### 历史云线没有关联元素

历史无绑定记录仍可查看，但详情会显示 **历史批注未关联元素**。本期不自动猜测目标，也不支持保存后改绑。
