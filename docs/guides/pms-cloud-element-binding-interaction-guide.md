# PMS 三维校审云线与模型元素绑定操作说明

## 1. 适用范围

本文用于指导设计人员和校审人员通过 PowerPMS 进入三维校审，完成校审单发起、云线绘制、模型元素绑定、自动截图、确认保存及双向查找。

- PMS 入口：`http://pms.powerpms.net:1801/sysin.html`
- 验证模型：Aveva Marine Sample
- 验证元素：BRAN `24381_145018`
- 支持关系：一条云线可关联一个或多个模型元素；同一模型元素可关联多条云线

> 账号和密码按项目内部测试账号管理规定获取，不要写入文档、截图或提交记录。

## 2. 角色与默认界面

| 角色 | 默认行为 | 可执行操作 |
| --- | --- | --- |
| 设计人员（SJ） | 进入三维校审后默认不显示“发起编校审”面板；校审区只允许查看、处理当前单据已有批注 | 显式打开“发起编校审”、选择模型、填写校审单并送审 |
| 校对人员（JH） | 从 PMS 待办进入对应校审单，显示当前流程节点和待处理批注 | 新建云线、绑定元素、确认数据、定位高亮 |
| 审核/批准人员 | 按 PMS 流程节点进入任务 | 查看绑定关系、模型定位及后续流程处理 |

SJ 如需发起校审单，必须主动选择顶部菜单“校审”中的“发起编校审”。关闭该面板后，界面恢复默认校审工作区。

## 3. 发起并送审

### 3.1 进入三维校审单

1. 登录 PowerPMS。
2. 进入“业务中心”。
3. 依次选择“设计交付”→“三维校审单”。
4. 点击“新增”打开三维校审窗口。
5. 等待模型树、三维视图和校审面板加载完成。

进入后应看到“外部流程 SJ 入口仅支持查看和处理当前单据已有批注”的提示；此时不应默认显示“发起编校审”表单。

### 3.2 显式打开发起面板

1. 点击三维窗口顶部“校审”。
2. 选择“发起编校审”。
3. 在右侧面板添加校审模型：
   - 可先在模型树选择元素，再使用当前选择；
   - 也可在参考号输入框输入 `24381_145018` 后按 Enter。
4. 填写校审包名称、说明以及校核、审核、批准人员。
5. 点击“保存编校审单数据”。

保存成功后，右侧显示绿色成功提示，并列出校核人、审核人和构件数量。

### 3.3 提交 PMS 流程

1. 点击 PMS 校审单窗口上方的“送审”。
2. 选择流程“三维编校审”。
3. 分别指定校核、审核和批准人员。
4. 点击“提交”。

提交成功后，三维校审任务进入校对节点；校对人员可在 PMS 首页待办或“三维校审单”列表中打开该任务。

## 4. 绘制云线并绑定模型元素

### 4.1 打开校对任务

1. 退出 SJ 或清理当前登录状态。
2. 使用校对账号登录 PMS。
3. 在待办列表找到对应“三维校审单”。
4. 打开任务并确认右侧校审区显示当前节点“校对”和状态“待处理”。

### 4.2 选择关联目标

1. 在模型树或三维视图中选择目标元素。
2. 点击批注工具栏中的“云线批注”。
3. 在“关联元素”区域选择一种方式：

| 方式 | 操作 | 适用场景 |
| --- | --- | --- |
| 使用当前选择 | 读取模型树或视口当前选中的元素 | 已经选好单个或多个目标 |
| 点选目标 | 连续点击模型，按 Enter 确认 | 目标分散，需要逐个追加 |
| 框选目标 | 在视口拖出选择框 | 目标集中，需要批量选择 |

4. 检查目标标签和“关联元素 N”数量。
5. 如有误选，可逐项移除或清空后重新选择。

没有关联目标时，系统禁止选择锚点和绘制云线，并提示“请先选择目标元素”。修改目标集合后，原锚点自动失效，需重新选择。

### 4.3 设置锚点并绘制

1. 目标确认后，在模型上单击云线锚点。
2. 出现“锚点已就绪，请拖拽绘制云线轮廓”提示后，在三维视图中按住鼠标拖拽。
3. 松开鼠标完成轮廓。
4. 点击“保存批注”。

保存成功后：

- 云线与最终目标集合一并保存；
- 锚点单独记录，不会重复计入关联元素数量；
- 当前三维视角自动保存为 PNG 问题截图；
- 当前模型的“关联云线”入口立即显示对应云线。

## 5. 确认、截图和恢复

1. 点击右下角“确认当前数据”。
2. 在确认浮层中核对批注数量。
3. 点击“确认完成”。
4. 右侧详情应显示确认时间、批次数量和批注数量。

展开云线详情后，可看到：

- “问题截图”：查看保存批注时自动截取的三维视角；
- “重拍”：以当前三维视角替换问题截图；
- “关联元素 N”：显示每个目标的 Noun 和 RefNo；
- “云线锚点”：单独显示锚点元素。

确认后刷新页面、重新进入任务或重新登录，绑定、锚点和截图均应恢复。

## 6. 双向查找与高亮

### 6.1 从云线查找模型元素

在云线详情的“关联元素”区域：

- 点击“定位高亮全部”：加载全部成功可用的关联元素，统一高亮，并对合并包围盒执行一次相机聚焦；
- 点击单个元素的“定位高亮”：只加载、聚焦和高亮该元素。

如果部分元素加载失败，系统高亮成功项并提示失败数量；全部失败时保留原视角和原选择。

### 6.2 从模型元素查找云线

1. 在模型树或三维视图选择一个元素。
2. 查看视口中的“当前模型关联云线”入口。
3. 展开后查看与该元素关联的云线数量和名称。
4. 点击目标云线，在三维视图和校审详情中查看对应批注。

同一元素关联多条云线时，列表逐条展示；同一元素同时作为目标和锚点时，反查按目标关系展示，不重复计数。

## 7. 操作状态与反馈

| 当前状态 | 用户操作 | 系统反馈 |
| --- | --- | --- |
| 未选择目标 | 点击模型或尝试绘制 | 阻止操作并提示先选择目标元素 |
| 已选择目标 | 点击模型 | 保存锚点并提示开始拖拽 |
| 已设置锚点 | 拖拽视口 | 显示云线轮廓预览 |
| 修改目标 | 追加、移除或清空目标 | 清除旧锚点和预览 |
| 点选/框选中 | 按 Enter | 确认目标并返回云线模式 |
| 点选/框选中 | 按 Esc | 取消当前拾取，保留此前确认的目标 |
| 云线工具中 | 按 Esc、关闭工具或切换工具 | 清空本次目标、锚点和预览 |
| 保存成功 | 再次绘制 | 清空本次创建状态，保留云线工具 |

## 8. 常见问题

### 三维窗口提示模型地址接口连接失败

这是 PMS 到三维站点的临时连接异常。返回“三维校审单”列表后重新点击“新增”或重新打开待办；不要连续重复提交同一校审单。

### 流程人员列表为空

先确认当前项目组织，再重新选择流程节点并查询人员。测试流程通常使用 SJ 发起、JH 校核、SH 审核、PZ 批准，实际项目以组织权限为准。

### 无法开始绘制

确认“关联元素”数量至少为 1。若使用三维包围盒云线，还需确认目标模型已经加载且能取得包围盒。

### 定位后没有高亮

检查 RefNo 是否属于当前输出项目、模型是否加载成功。部分目标失败时先根据提示核对失败数量，再单独定位问题元素。
