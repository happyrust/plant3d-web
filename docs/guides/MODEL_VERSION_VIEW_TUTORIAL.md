# 模型按版本显示（节点版本 / 历史对比）使用教程

「节点版本」面板让你把模型里任意一个节点的**历史版本**拉出来看：谁在哪个会话（sesno）改了什么属性、那一版的三维长什么样、和另一版比哪些构件新增 / 删除 / 修改。
三维里装出来的是服务端**按那个会话重算的历史投影**（不是给当前模型换个颜色），周围环境仍是最新模型——所以叫「混合时间视图」。

> 版本 = E3D 数据库的一次**保存会话**（sesno）。面板上所有「版本」都指 sesno；时间线一行 = 一个会话。

## 1. 前置条件

- 前端连的 gen-model 服务端要带版本路由（`model/versions`、`model/history/generate | query`、`element/versions`、`node/versions`……），即 **gen-model-refactor `a382b2cf3`（0.1.27）以后**的构建。旧服务端打开面板会在对应位置**照实说**「服务端还没有 xxx 路由」，能看的那一半照常能看，看不了的那一半置灰或退回手填会话号。
- 三维查看器已打开、目标 dbnum 的模型已加载（环境用的就是它）。
- 数据库开着增量：gen-model 自己监听 E3D 库变化生成版本表，不用你做什么。

## 2. 打开面板：四个入口

| 入口 | 怎么点 | 适合什么时候 |
|---|---|---|
| **模型树右键** | 在模型树里右键任一节点 → **「查看历史版本」** | 已经在树里找到那个构件 / 管道 |
| **属性面板「历史」** | 三维里点选一个构件，右侧属性面板标题栏点 **「历史」** | 正在看某个构件的属性，想知道它是什么时候变的 |
| **Ribbon 菜单** | **任务 → 版本对比** 打开面板，在输入框填节点参考号（`24384_23262` 或 `24384/23262`）→ **查询** | 手里有参考号 |
| **URL 直达** | `/?unit_refno=24384_26480&compare_a=626&compare_b=630&compare_autorun=1` | 分享 / 复现某一对版本：开页即自动查、选 A / B、跑对比 |

面板打开后标题是 **「节点版本」**，头部一行说明这个节点是什么：`DB 8000 · 24384_23262（FTUB） · 所属单元 24384_23257（BRAN）`，或 `· 最小交付单元根`，或 `· 容器，不属于任何最小交付单元`。

## 3. 读时间线：本范围 n 版、A / B、筛选

面板上半是**版本时间线**，标题 **「版本时间线 · 本范围 n 版 · 仅属性 m」**：

- **n** = 服务端版本表里这个节点在当前范围下变过的会话数；
- **仅属性 m** = 只改了不进模型提取的属性（UDA 之类）的会话——它们不算一版，但列出来（谁在哪一版改了什么，要它），行上标 **「仅属性」**。

每一行：`sesno · 时间 · 保存人 · 备注 · 属性 n（改了几项）· 影响芯片`（`mesh` 几何变了 / `delivery` 交付 / `noop` 没变 / `tombstone` 被删……；「所有子节点」下还会有 **「单元 n」** = 这一会话子树里有几个交付单元的几何要重算）。

**选 A / B（要比的两版）**：

- 每行左侧一对 **A** / **B** 小按钮，点哪行就把哪版设成 A 或 B；系统自动保证 A 早于 B，撞到同一版时另一端自动让开。
- **「与上一版比」**：B 不动、A = B 的上一版；**「与最新比」**：B = 范围内最新一版。
- 缺省 = 范围内最近两版。当前 A / B 显示在按钮行右侧的蓝 / 绿徽章上。

**筛选与折叠**：

- **「只看几何变的」**：去掉影响为空 / `noop` 的行。
- **「只看自身变的」**（只在「所有子节点」下露出）：子树里别的构件动了、这个节点自己没动的会话不列；只改了属性的算自己变过。自身列服务端没给时置灰。
- 时间线缺省只画**最近 20 行**，底下一行 **「加载更早 n 版…」** 点开全列（版本表早已整表取回，不再请求服务端）。被选为 A / B 的行永远看得见——选到很早的会话时那一段会自动露出来。
- 被选中但已不在当前范围里的行灰掉、标 **「本范围无变化」**，不会丢。

## 4. 对比范围：仅自身 / 所有子节点

面板头部 **「对比范围」** 开关，三块（时间线 / 属性对比 / 模型对比）都受它约束：

| 范围 | 时间线列什么 | 缺省 |
|---|---|---|
| **仅自身** | 只列这个节点**自己的记录**变过的会话 | 叶子构件（FTUB / VALV……，没有成员）只有这一档，「所有子节点」置灰 |
| **所有子节点** | 列它**子树里任何东西**变过的会话（几何按交付单元折叠成「单元 n」） | 带成员的节点（单元根、容器）缺省这一档；容器缺省仍是「仅自身」 |

切范围时 A / B 保留。

---

## 5. 属性对比：两版之间属性的净差

下半第一个 tab **「属性对比」**，看 A → B 之间**属性**上的变化（不是几何）：

- **仅自身**：一张表 `属性 · A 值 → B 值`，标题 **「A 626 → B 630 · n 项变化」**。改过又改回去的不算变化（服务端两端直接读终态给净差；旧服务端没有 `element/attribute-diff` 时退回把时间线在 (A, B] 里折出来，表底会写明）。`CACHID` 一类「戳」缺省不列，勾 **「含戳」** 才列。成员增删 / 重排、owner 改挂另说一句。
- **所有子节点**：先列 **「有变的构件 n 个」**——差异摘要里有变的构件清单，本节点置顶标 **「本节点」**，每行 `类型 refno · 状态（新增 / 删除 / 修改 / noop）· 影响`；点一行展开拉它自己的净差表；每行右侧 **「定位」** 飞到三维里的它（装着 A / B 时飞隔离图层里那一版的它，被删的也找得到；没装时飞当前模型里的它；B 版已删且没装 A / B 时置灰）。

---

## 6. 模型对比：把两版几何装进三维

下半第二个 tab **「模型对比」**：

1. 先出 **差异摘要**（`A 626 → B 630 · 差异摘要（未生成几何）`）：变了的单元 / 未变单元、构件新增 / 删除 / 修改 / noop——这是一张账，**没有去生成几何**，秒回。
2. 点 **「在三维中对比」**：服务端按 A、B 两个会话各生成一份**历史投影**（第一次几秒到十几秒，之后有缓存），三维里把它们装进两个隔离图层，环境里同一单元的当前几何暂时藏起来。
3. 装完面板下方出 **「三维查看」** 运行态卡（见下一节）和 **几何差异** 摘要（新增 / 删除 / 修改 / 未变 四个数）+ 差异列表（`全部差异 / 新增 / 删除 / 修改` 筛选，**「包含未变化」** 把没变的也列出来）；点列表一行 = 三维里飞过去。
4. 几何是**最小交付单元级**的：查一个构件（FTUB）装的是它所属的整条 BRAN，跑完自动把结果收窄到它、选中并定位。两版几何相同（同一 `geometryKey`）时只装一份，摘要写「无几何差异；A/B 几何相同，只加载了一次」。

## 7. 三维里怎么看：切 A / B、分屏、只看差异、点构件

装好后视口左上角有 **版本角标**（`A · sesno 626` 蓝 / `B · sesno 630` 绿），下面一行 **四态图例**：

| 颜色 | 含义 |
|---|---|
| 琥珀 | 修改（两版都有、几何不同） |
| 翠绿 | 新增（只在 B） |
| 玫红 | 删除（只在 A） |
| 石板灰 | 未变 |

版本身份只由角标说（不再「A 整侧蓝、B 整侧绿」），颜色说的是**这个构件变没变**。

面板 **「三维查看」** 卡上：

- **「单视口切换」**：一个视口，点 **A 卡 / B 卡** 切着看（缺省显示 B）。
- **「双视口分屏」**：左 A 右 B 同一相机；从管道逐组看时分屏会一直保持，不用每组再点一次。
  - 这台机子没有显卡加速（远程桌面 / 虚拟机）时，分屏摘要下会写一句「这台机子是软渲染……分屏走直接渲染」：那时选中的环境构件按选中色显示、没有描边，帧率优先。
- **「三维只看差异」**：藏掉两版都没变的构件，只剩新增 / 删除 / 修改；与列表的「包含未变化」同一口径、各自开关。本次没有几何差异时置灰。
- **「最新环境 · 刷新」**：环境永远是 dbnum 的最新模型，这里显示已固定的加载范围，点刷新重取。

**点三维里的构件**：

- 点到 A / B 隔离图层里的构件 → 右侧属性面板顶上出琥珀横幅 **「属性来自版本 B · sesno 630」**，下面列的是**那一版**的属性（版本钉住），不是当前会话的；分屏里左格点的读 A、右格点的读 B。
- 点环境构件 → 普通选中，横幅撤掉；点空处清空。
- 被删的构件（只在 A 里）也能点、也能定位——树差异模式里它是幽灵行。

## 8. 模型树差异模式与「已删除」的构件

「在三维中对比」跑完，模型树同步进入 **差异模式**（`626 → 630`）：

- 变了的构件带徽章（改 / 增 / 删），未变的不标；
- 在 B 已被删的构件以 **幽灵行**回插到原父下，标 **「（已删除）」**；A 之后建、B 之后又被删的标 **「当前已不在」**；
- 底部 **「属性历史对比」** 面板列 A / B 两版逐项属性（`该构件在版本 B 不存在` 之类横幅照实说），**「在 3D 中定位」** 飞到它；
- 右侧属性面板对被删的构件显示 **「该构件已删除，属性见底部属性历史对比」**，不会去拉当前会话的属性报 404。

退出对比时差异模式一并退出。

## 9. 容器（管道 / 区域 / 站点）怎么看

PIPE / ZONE / SITE 这类容器**没有自己的几何**，几何都在其下的最小交付单元（BRAN / EQUI……）里：

1. 查容器 → 缺省「仅自身」只列它自己记录变过的会话；切 **「所有子节点」** → 时间线来自 `node/versions`（子树里任何东西变过的会话，行上「单元 n」）。
2. **模型对比** tab 的差异摘要**按单元分组**：每组 `BRAN 24384_23257 · 新增 / 删除 / 修改` + 一颗 **「在三维中对比」**——装那一个单元的 A / B（单元在 A 时还没建 / 在 B 时已删的，那一侧显示空态、注「该版本没有这个单元」/「该版本单元已删除」）。
3. 不止一组时列表上方有 **「全部变了的单元一起进三维」**（`N 个单元 · 约 M 份历史投影`）：所有变了的单元一起装，进度卡 **「正在生成历史投影 n / m」**；超过 **20 个**单元或服务端提示超阈值时先问一句——**全部生成 / 先装变化最大的 20 个 / 取消**。装好后 A / B 卡会列出这一侧不存在的单元，运行态卡写「N 个单元 · <容器> 下」。点某一组的按钮 = 只看那一组。
4. 顶部主按钮「在三维中对比」对容器置灰（它自己没几何）。
5. URL 直达对容器也生效：`compare_a / compare_b` 套到时间线上（本范围没有、子树有就自动切「所有子节点」），落到模型对比 tab 看分组即停，不自动装几何。

---

## 10. 退出与收尾

- 「三维查看」卡右上 **「退出」**（或视口里的关闭）：卸掉两个隔离图层、恢复环境里被藏的当前几何、相机回到对比前、模型树退出差异模式、服务端上的历史快照 **DELETE** 掉。
- 换节点重新「查询」、换 A / B 重跑，都会先自动退出上一轮。

## 11. 限制与常见疑问

| 问题 | 回答 |
|---|---|
| 能同时看三版以上吗？ | 不能。一次是 **A / B 两版**对比；只想看某一版，把它选成 A 或 B、单视口切到那一侧即可。 |
| 能把整个库回到某一天吗？ | 不能。环境**永远是最新模型**，只有被查的单元（或容器下选中的那些单元）是历史版本——这是有意的混合时间视图（CONTEXT Q12）。 |
| 为什么查一个 FTUB 装出来一整条 BRAN？ | 几何按**最小交付单元**生成，FTUB 自己没有独立几何；跑完会自动收窄到它。 |
| 为什么「本范围 n 版」和某一行的属性数对不上？ | n 按服务端版本表（模型口径：模型变没变）数；「属性 n」来自属性变化时间线（改了什么）。只改 UDA 的会话进后者不进前者，所以单独标「仅属性」。 |
| 时间线只有 20 行？ | 缺省折起更早的，点底下 **「加载更早 n 版…」**。 |
| FTUB 只挪了位置却标 `mesh` 而不是 `placement`？ | 服务端分类器口径，前端只照转。 |
| 分屏比单视口暗 / 选中没描边？ | 软渲染（无显卡加速）下分屏走直接渲染；有显卡时分屏每格都走描边合成器，与单视口一致。 |
| 面板说「服务端还没有 xxx 路由」？ | 连的 gen-model 太旧（要 `a382b2cf3` 以后）。能看的那半照常能看。 |
| 历史投影很慢？ | 第一次按会话重算几何要几秒到十几秒，之后有缓存；多单元一起装时看进度卡，一次上限 20 个单元。 |
