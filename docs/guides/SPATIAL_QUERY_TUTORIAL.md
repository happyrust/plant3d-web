# 空间查询（按范围显示）使用教程

空间查询功能用于在三维场景中，以指定中心点和半径为条件，查找周围的构件并控制其显示/隐藏。适用于在大型工厂模型中快速定位和查看特定区域的管道、设备等。

## 3. 设置查询中心

范围查询需要指定一个中心点，有三种方式：

| 方式 | 说明 |
|------|------|
| **当前选中** | 以当前在场景中选中的构件的包围盒**中心点**作为查询中心 |
| **拾取中心** | 在场景中点击一个构件，以该点位置作为中心 |
| **手输坐标** | 手动输入 X、Y、Z 坐标（毫米单位） |

操作步骤：

1. 在「中心来源」区域选择一种方式
2. 若选择"当前选中"，先在场景中点选一个构件，再点击 **「使用当前选中」** 按钮
3. 若选择"手输坐标"，直接在 X/Y/Z 输入框中输入坐标值
4. 面板右侧的坐标指示器会实时显示当前中心坐标

> **半径量到「一个点」还是「整个包围盒」？两种口径别混。** 半径的起算方式取决于中心怎么来的：
> - **点中心**（拾取中心、手输坐标，以及「当前选中」一个**已加载几何**的构件——取它包围盒的**中心点**）：半径量的是到那**一个点**的距离（服务端 `aabb_point_distance`）。「半径 3 m」= 离该点 3 m 的球 / 立方体。
> - **包围盒中心**（「当前选中」一个**未加载几何**的构件，如 PIPE / ZONE 这类 owner；以及距离查询的「通过 Refno」——见 §8）：中心由服务端按该构件**整个包围盒**解，半径量的是到**盒表面**的最近距离（`aabb_min_distance`）。「半径 3 m」= 离该构件包围盒 3 m，**构件越大（整间房 / 整根 BRAN / 大设备），命中的「附近」范围越大**；房间自己的墙贴着盒，距离会是 0。
>
> 举个例：同一间房 R432、同样「半径 3 m」，用 `?refno=<房间>`（到盒）会命中约 3900 条（整间房 + 3 m 边），用 `?x/y/z=<房间中心点>`（到点）只命中约 1300 条（离中心点 3 m 的小球）——两者都对，只是问的问题不同。要「离某一点 N 米」就用手输坐标 / 拾取中心；要「离某个构件 N 米」就用 refno。

![查询形状和半径](images/spatial-query/05-shape-radius-settings.png)

## 4. 选择查询形状与半径

半径在面板主体直接调（输入框 / 滑条 / 1、5、10、50 m 预设，单位 **米**，上限 100 m）；查询形状、结果排序、每页数量与下面 §5 的过滤项
都收在 **「更多条件」** 折叠块里，点「展开」才出现。

| 参数 | 说明 | 默认值 |
|------|------|--------|
| **查询形状** | 球形（推荐）或立方体 | 球形 |
| **查询半径** | 搜索范围，面板按米显示、内部按毫米发请求 | 5 m（5000 mm） |
| **结果排序** | 按距离（由近及远）/ 按专业（先专业后距离，仅 legacy 源）/ 按名称（gen-model-v1 源下服务端只为本页补名字、全集按 Noun / Refno 近似排，选中时按钮下方与结果区都会提示，见 §9） | 范围查询按专业（gen-model-v1 源下按距离）、距离查询按距离 |
| **每页数量** | 服务端分页，每页返回多少条；填空或不是 ≥ 1 的整数时输入框标红、「执行空间查询」灰掉 | 100 |

- **球形**：以中心点为球心，半径为搜索范围，适合大多数场景
- **立方体**：以中心点为中心的正方体范围，边长 = 2 × 半径

> 提示：半径 5 m 适合查看局部管道走向；如需查看更大范围，可调大半径至 10–50 m。
> 半径上限 100 m 是服务端硬限，面板输入、URL 参数（`?spatial_refno=…&spatial_radius=…`）与最终请求三处都会钳到 100 m。

## 5. 配置过滤条件

「更多条件」展开后可以精确筛选结果：

![过滤条件](images/spatial-query/06-filter-conditions.png)

| 过滤项 | 说明 | 示例 |
|--------|------|------|
| **Noun 类型** | 逗号分隔的构件类型代码 | `PIPE,EQUI,BRAN` |
| **房间过滤**（2026-09-20 起，仅 gen-model-v1 源） | 可搜索的多选下拉（按房间号 / 名称 / Refno 过滤在册房间），点选加进已选；输入框里直接敲房间号回车按**房间号精确加入**（同一个房间号对应多间房时全部选上并提示，可再删）；「当前选中所在房间」把查看器 / 模型树里当前选中构件所在的房间一键带入。**已选多间 = 只保留房间归属含任一所选房间的构件**（横跨两间房的管子两边都算）。服务端未开启房间归属计算（`room_membership=false`）、房间模型未就绪或 legacy 源时此块收起 / 换成一句原因，见 §9 | `A101`；`A101, B202` |
| **专业筛选** | 按工程专业快速过滤。legacy 源一直有；gen-model-v1 源 2026-09-20 起也有——服务端按构件所属 SITE 的名称关键字派生（与 legacy 同一规则：PIPE→管道、ELEC/电气→电气、INST→仪表、HVAC→暖通、CIVI/ARCH→土建、STRU→结构，其余「其他」；规则表在服务端 `DbOption.toml` 的 `spec_value_rules`） | 管道、电气、仪表、暖通、土建、结构、其他 |
| **关键字** | legacy 源按 Refno / Noun / 名称匹配；gen-model-v1 源只按 Refno / Noun（见 §9），输入框文案随源切换、不再许诺「名称」 | 输入部分 Refno、Noun 或名称 |
| **仅看已加载** | 只在已加载到场景中的构件里找 | - |
| **仅看当前可见** | 只在已加载且当前可见的构件里找 | - |
| **显示负实体** | 把 NBOX / NCYL 这类负实体也列出来（默认剔除） | - |

**「仅看已加载 / 仅看当前可见」的查法**：这两项的结果必然是已加载构件的子集，所以中心是点（当前选中有包围盒、拾取、手输坐标）时
**不打服务端**，直接扫描查看器里已加载的构件，一次给全、不分页、按所选排序在前端排好——结果区分页行会显示「本地扫描（仅已加载构件）· 共 N 项 · 不分页」。
只有中心必须由服务端解的情况（距离查询「通过 Refno / 沿 BRAN 中心线」，或「当前选中」选的是没加载几何的 PIPE / ZONE 一类 owner）仍走服务端，
这两项在**本页内后筛**，结果区会提示「总数与页数按服务端全量计」。**勾了房间过滤时也一样走服务端**：房间归属只有服务端判得出，
本地扫描独有的命中（已加载但服务端索引里没有的构件）这时不再补进结果，结果区会说一句。

> 提示：不设过滤条件则查询范围内所有类型的构件。房间 / 专业两个维度在两个 Tab（范围 / 距离）之间共用。

## 6. 执行查询与查看结果

设置好条件后，点击橙色的 **「执行空间查询」** 按钮。

![执行按钮与结果区](images/spatial-query/04-filter-and-execute.png)

以下为一次实际查询的结果（中心 (0,0,0)，半径 5000mm），显示 **共 100 项，已加载 0 项，未加载 100 项**：

![查询结果总览](images/spatial-query/07-query-results.png)

查询过程分为以下阶段（按钮上会实时提示）：

1. **解析中心点** → 将选中 / 拾取 / 坐标换成 E3D 世界坐标（mm）
2. **查询空间索引** → 向服务端发送请求；服务端在分页前完成排序与 Noun / 关键字 / 负实体过滤，回一页结果与全量计数
3. **扫描已加载模型** → 以同一个中心和半径在查看器已加载的构件里检测包围盒相交（与服务端同一套「盒到点的最近表面距离」口径）
4. **合并结果** → **服务端为准、本地补漏**：两边都有的构件合成一条（名称、距离取服务端，已加载 / 可见状态取查看器）；
   只有本地命中、服务端整个命中集合里都没有的已加载构件（gen-model-v1 的空间树不收 TUBI；索引也可能落后于场景）
   追加在**第 1 页末尾**，计入「共 N 项」但不改变服务端的页数

「仅看已加载 / 仅看当前可见」（点模式）跳过第 2 步，只做本地扫描，见 §5。

查询完成后结果区默认**收起**，只显示摘要（「共 N 项，当前页 M 项，已加载 / 未加载」与按专业 / 按库的分项计数）；点 **「查看结果」** 展开。
结果按 **专业分组** 显示；gen-model-v1 源下结果区多一个 **「按专业 | 按库」** 两态切换（缺省按专业，切到按库时组头是「库 24381」、按钮改为
「加载本库 / 仅显示本库」，见 §9），每个结果项包含：

- 构件名称和 Refno
- Noun 类型标签（如 SNOU、NBOX、BOX 等）
- 已加载/未加载状态标签
- 与中心点的距离

![结果列表详情](images/spatial-query/08-result-list-detail.png)

**分页**：结果按「每页数量」分页，底部「上一页 / 下一页」在服务端翻页。翻页和切换排序都**沿用这次查询已经解出的中心与条件**——
期间在查看器里换了选中、或点空白清掉选中，都不影响后面几页；翻页失败（服务端空间树未就绪的 503、网络抖动）只显示错误条，已拿到的页不会被清掉。
要按新的选中 / 新的条件查，点「执行空间查询」。

## 7. 结果操作：显隐、隔离、加载

摘要行下面常驻三个按钮：

| 按钮 | 功能 |
|------|------|
| **加载当前页** | 只加载**这一页**列出的构件（未加载的下载几何，已加载的保持），加载完飞到它们 |
| **只加载未加载** | 把**整个命中集合**（跨页）里还没加载的都补上 |
| **清空** | 清掉本次结果 |

展开结果后还有一组作用于**整个命中集合**（有翻页时按服务端给的全集，取不到全集才退回当前页）的按钮：

| 按钮 | 功能 |
|------|------|
| **全部显示** | 将结果中所有构件设为可见 |
| **全部隐藏** | 将结果中所有构件设为隐藏 |
| **隔离结果** | 将场景中非结果构件设为半透明（X-Ray），仅高亮结果集 |
| **恢复场景** | 取消隔离效果，并把「全部隐藏 / 仅显示本专业（本库）/ 单项眼睛」动过的构件放回**动之前**的显示状态；连做几步也回到最初那一份 |
| **复制当前页 Refno** | 把当前页的 Refno 按显示顺序复制到剪贴板（一行一个） |
| **复制已返回 Refno** | 复制当前已返回的全部 Refno（去重） |

> 跨页的批量加载（「只加载未加载」、分组「加载本专业 / 本库」）超过 **200 个**会先弹确认框并显示数量——1387 项那次点下去 3 分钟没回来；
> 「加载当前页」按页算，不弹。

全集有服务端上限（gen-model-v1 `result_cap` = 100000 项；legacy「沿 BRAN 中心线」一页最多 10000 项）。命中超过上限时结果区会提示
「完整命中集合已截断：只取到 N / M 项，服务端上限 …」，上面这组跨页按钮只作用于取到的那 N 项；全集接口失败时提示「完整命中集合取不到」，
这组按钮退回只作用于当前页。两种情况都请缩小半径或加过滤条件再查。

每个专业分组还有独立的操作（gen-model-v1 源下分组按库，按钮相应叫「加载本库 / 仅显示本库」，见 §9）：

- **加载本专业**：仅加载该专业下的未加载构件（跨页）
- **仅显示本专业**：隐藏其他专业，仅显示该专业的结果

单个结果项的操作：

- 点击 **眼睛图标**：切换该构件的显示/隐藏
- 点击 **箭头图标**：飞行定位到该构件
- 点击 **整行**：高亮选中并定位到该构件，同时成为全局选中（属性面板 / 模型树跟着切到它，与在查看器里点选一样）
- 距离查询「通过 Refno」下多一个 **尺子图标**：对源 refno 与这一行做外表面净距标注

**房间列表**：展开结果后，结果区会解析**当前页**构件所在的房间（按房间去重、显示每间落了几项），可点「信息」看房间属性、「显示」加载该房间模型。
结果区收起时不解析；这两条查询走旧后端 `/api/room-tree` 与 `/api/pdms/ui-attr`，旧后端没起时显示「当前页暂未解析到房间」。

**迷你模式**：面板右上角「迷你」把面板收成一张小卡（模式、半径、结果数与分项计数），「展开面板」回来。

## 8. 距离查询模式

切换到「距离查询」Tab，可以查询两点/两构件之间的距离：

- **通过 Refno**：输入起始物项的 Refno（如 `24381_100818`）。半径量的是到该构件**整个包围盒**表面的最近距离（不是到一个点）——口径同 §3 的「包围盒中心」那一档，构件越大「附近」越靠外；要按「离某一点 N 米」查请改用「通过坐标」。（gen-model-v1 源下还多一档「沿 BRAN 中心线」，沿各段中心线量距，半径即走廊外扩距离。）
- **通过坐标**：手动输入起始坐标，半径量到该点。

后续的半径、过滤条件和结果操作与范围查询一致。

## 9. gen-model-v1 数据源下的差别

2026-09-09 起页面缺省数据源是 **gen-model-v1**（`?model_source=` 不写就是它；`?model_source=legacy` 回旧链路，开关与起服务的方法见
`gen-model-v1-local-dev.md` §1 / §3）。这一源下，范围查询与距离查询不再走旧后端的 `/api/sqlite-spatial/*`，而是查 gen-model
进程内的空间树（`GET /api/v1/spatial/{nearby, nearby/refnos, negative-nouns, rooms}`，契约在 gen-model 仓 `docs/specs/web-service-api.md`
§4.13 / §4.13.4；实施记录见 `docs/plans/2026-09-13-spatial-range-query-gen-model-v1-memory-tree-plan.md` 与
`docs/plans/2026-09-20-spatial-query-room-and-discipline-filter-plan.md`）。面板操作完全一样，可见差别有七处：

| | legacy 源 | gen-model-v1 源 |
|---|---|---|
| **覆盖面** | 旧后端离线建好的全库空间索引 | **只有已生成过模型的构件**：空间树只收进过树的包围盒，从没显示过（没 `ensure` 过）的构件不在其中。结果区顶部会提示「结果仅含已生成过模型的构件…先显示它们再查会被纳入」 |
| **专业维度** | 专业筛选、「按专业」排序、按专业分组、「加载本专业 / 仅显示本专业」 | 2026-09-20 起**同样有**：服务端按构件所属 SITE 名的关键字派生专业（与 legacy 同一规则，ADR 0067），专业筛选 / 「按专业」排序 / 专业分组原样可用；此外结果区多「按专业 \| 按库」切换——按库时组头「库 24381」、小计是服务端的全量计数（全集有而本页没有的库也露组头），按钮改为「加载本库 / 仅显示本库」。此前（09-13 至 09-20）v1 源没有专业维度、只按库分组 |
| **房间过滤** | 没有（旧后端没这一格；抽屉里不画房间块） | 「更多条件」里多**房间过滤**：清单来自服务端在册房间（`GET /api/v1/spatial/rooms`），过滤在服务端分页前做，「共 N 项」/ 分组 / 分页 / 批量操作因此一致。服务端 `room_membership=false`（缺省就是关的）时此块只剩一句「服务端未开启房间归属计算」；房间模型正在装载时提示稍后再试。读透形态（`store_mode=mem`）下归属按候选的内存投影现算：本进程没再显示过的构件判不出归属、会被剔除并在结果区警告「N 个候选没有内存投影记录…先显示它们再查会被纳入」 |
| **距离查询的起点 Refno** | 索引里没有 → 空结果 | 该构件还没生成过模型 → 提示「构件 X 还没有生成过模型，空间索引里没有它的包围盒；请先显示该构件，再按距离查询」。先把它显示出来（勾眼睛，或 `?show_refno=`）再查；接口不会替你隐式生成 |
| **服务端空间树未就绪** | — | 服务刚启动、快照重建中、或以 `AIOS_SPATIAL_COMPUTE=0` 起的进程，接口回 503 `spatial_not_ready`（带 `Retry-After: 5`），面板把它当一次查询失败显示、错误文本尾部带「约 N 秒后可重试」；翻页 / 改排序时撞上它，已拿到的页保留、只显示错误条。稍等几秒重查即可。`GET /api/v1/health` 里 `spatial_tree.state` 为 `ready` / `ready_empty` 才能查 |
| **TUBI 等隐含管子** | 索引里有 | 空间树不收 TUBI；已加载的 TUBI 靠本地扫描补进第 1 页（见 §6 第 4 步），没加载的查不到 |
| **「按名称」排序** | 服务端按名称排整个命中集合 | 服务端**只为本页补名字**，整个命中集合按 Noun / Refno 近似排（读名称要回元素记录，对全部候选做会拖成秒级）：跨页顺序不是名称序。选中「按名称」时按钮下方给提示，结果区也带一条警告 |

其余口径不变：单位 mm、球形 / 立方体、半径上限 100 m（100000 mm）；服务端关键字只匹配 Refno 与 Noun（**不匹配名称**——v1 源下名称只对本页补，
全集匹配名称要对全部候选读记录，大半径下会拖成秒级）；负实体（NBOX / NCYL 等）默认剔除；「加载当前页 / 只加载未加载」在 v1 源下直接走
`ensure → records` 取几何，不再探 parquet、也不触发旧后端的批量生成。结果区展开后的「房间列表」（当前页条目所在房间）在 v1 源下走
`e3d.room.lookup`（此前打旧后端 `:3100`，v1 下那条路是断的）。

> 想让某片区域的结果更全：先把那一片显示出来（或整库显示 `?show_dbnum=<dbnum>`，见 `gen-model-v1-local-dev.md` §3），再执行查询。

## 典型使用场景

### 场景 1：查看某设备周围的管道

1. 在模型树中选中设备
2. 打开空间查询 → 范围查询
3. 点击「使用当前选中」设为中心
4. 半径设为 10 m，「更多条件」里 Noun 类型填 `PIPE,BRAN`
5. 执行查询 → 查看结果 → 只加载未加载 → 隔离结果

### 场景 2：查看某区域内所有专业的构件

1. 打开空间查询 → 范围查询
2. 选择「手输坐标」，输入目标区域中心坐标（mm）
3. 半径设为 20 m，不设过滤条件
4. 执行查询 → 按专业分组查看

### 场景 3：快速加载局部模型

1. 在已加载的模型上选中一个构件
2. 打开空间查询 → 半径设为 5 m
3. 执行查询 → 点击「只加载未加载」（超过 200 个会先确认）
4. 系统会自动从服务端下载并加载周边几何体

### 场景 4：只看已经加载的构件里哪些在某点附近

1. 范围查询 → 手输坐标或拾取中心
2. 「更多条件」里勾「仅看已加载」（要排除隐藏的再勾「仅看当前可见」）
3. 执行查询 → 不打服务端，一次列全、不分页

## 注意事项

- 坐标单位是 **毫米（mm）**，面板上的半径按 **米** 显示（内部换成 mm 发请求）
- 查询范围过大时，建议配合 Noun 类型或专业筛选缩小结果
- "隔离结果"使用 X-Ray 效果，点击"恢复场景"可还原（连同被「全部隐藏 / 仅显示本专业」隐掉的构件一起放回）
- 翻页 / 改排序沿用本次查询已解出的中心，换了选中要重新点「执行空间查询」
- 未加载的构件需要从服务端下载，大批量加载时需等待
- gen-model-v1 源（缺省）下结果只含已生成过模型的构件、没有专业维度、结果按库分组；起点构件没生成过模型或服务端空间树未就绪时会给出对应提示，见 §9
