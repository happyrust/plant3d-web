# 管道连排相邻测量实施计划

- 日期：2026-10-19
- 状态：业务方向已确认；仅计划，尚未实施
- 项目：`plant3d-web`
- 本次授权：只新增本计划文档，不修改业务源码、后端、既有测试或运行中的命令。
- 分析依据：当前编辑器中的源码，包括现有工作区改动；本文所列新增文件和字段均为建议设计，不代表已经存在。

## 1. 已确认决策与非目标

用户已确认：

1. 支持「管中心成排」与「管底对齐」两种独立模式。
2. 第一版同时提供「截面中心距」与「外径推导间隔」。
3. 先落实施计划，不自动进入编码阶段。

第一版建议边界：

- 在现有「管道距离」入口增加「连排相邻」模式，保留原「所有管对」检测。
- 只分析用户明确选中的 BRAN；相邻指所选管道中的相邻，不保证覆盖全场景的物理邻管。
- 基于真实中心线、局部直段、共同轴向区段识别管排；只测每排内相邻管。
- 不修改后端，不把整 BRAN 实体最近净距当作局部排管区段净距。
- 不将 PCA 估算静默替换为正式中心线结果。
- 不默认包含阀门、法兰、支吊架或未明确建模并选择的保温外包络。
- 不覆盖无关的既有工作区改动，不重构整套测量或校审系统。

尚未由用户确认的工程默认值、字段名称与实现拆分，均在下文明确标为建议。

## 2. 当前实现基线

| 链路 | 当前行为 | 主要位置 |
| --- | --- | --- |
| 多管批量检测 | `all-pairs` 枚举所有已选管对，最多 4 个请求并发获取整对象外表面净距 | `src/composables/usePipeDistanceStore.ts` |
| 单管周边检测 | 查询周边 BRAN，再计算源管到各目标管的净距 | 同上 `detectNearbyBrans` |
| 交互式管—管 | 两条 BRAN 真实中心线合并直段，配平行直段对，记录中心距 | `src/composables/useDtxTools.ts`、`branParallelSpacing.ts` |
| 本地兜底 | 整批精算无成功记录时，对可见 DTX 网格拟合轴线；属于估算 | `PipeDistanceDrawer.vue`、`detectDtxBranchAxisDistances.ts` |
| 结果与标注 | `ClearanceStore` 为统一记录真相，外部尺寸源负责只读展示 | `src/clearance/stores/useClearanceStore.ts`、`useClearanceDimensionSync.ts` |

设计必须尊重以下现状：

- `clearanceRecordId` 当前只编码有向的源、目标编号，无法直接表达同一管对的多个区段和多种度量。
- `ClearanceSnapshot.distanceM` 当前是非负距离语义，`intersects` 表达相交；不能直接拿它保存负的名义间隔并冒充网格碰撞。
- `pipe-surface-clearance` 当前映射为 `exact-surface`，不能直接复用来标记新的圆柱模型推导值。
- 中心线接口已提供逐段外径与 `diameter_evidence`，来源包括 `catalogue`、`bore-estimate`、`missing`。
- `implicit=true` 的 `a_b~c_d` 是隐式管身标识，不是可直接当作普通构件编号请求实体接口的对象。

## 3. 业务定义

### 3.1 直段、区段与测量截面

- **直段**：同一 BRAN 中，共线、同径、端点连续的一组真实中心线段。
- **共同区段**：多条直段沿统一管向投影后，共同存在且参与集合稳定的一段轴向范围。
- **测量截面**：垂直于该组代表管向、位于共同区段内的一张平面。
- **管排**：该截面中，按所选成排规则可归为一排的管道集合。
- **相邻管对**：同一排中，沿排向排序后相邻的两条直段，不按点选顺序或编号大小决定。

同一对 BRAN 在不同弯折区段上可以有多条合法测量；不能整条 BRAN 只保留一个全局值。

### 3.2 管中心成排

在同一测量截面求各管真实轴线的交点 `C_i`，根据中心点近似共线识别管排，并沿排向排序。

多排、网格状排列或存在多个同等合理排向时，显示候选分组并要求确认，不强行压成一维排序。

### 3.3 管底对齐

给定截面内的单位支承法向 `n` 及各管外半径 `r_i`，定义：

`B_i = C_i - r_i * n`

用 `B_i` 判断管底对齐及进行排内排序。管底对齐只改变归排依据，不把中心距改成管底点距离或水平投影距离。

建议默认支承法向为世界向上方向在截面内的归一化投影。若投影退化，例如主管向与世界向上方向平行，必须提示指定支承法向，不根据相机朝向猜测。

两种模式独立切换，不自动为同一批管重复生成两套结果。默认先展示哪种模式属于待确认交互细节，建议先展示管中心模式。

## 4. 度量与证据

### 4.1 截面中心距

`D_cc = |C_j - C_i|`

两端必须位于同一测量截面、各自真实中心线上。轻微非平行时，该值随截面变化，因此记录必须保存测量截面位置，名称始终为「截面中心距」，不宣称整段轴线的全局最短距离。

### 4.2 外径推导间隔

`G_nominal = D_cc - (OD_i + OD_j) / 2`

这是平行圆柱模型的推导值，不是当前区段的真实网格精算。方向存在容差内小角差时，仍保留模型假设提示，不升级为全区段最小净距。

证据规则：

| 外径证据 | 结果行为 |
| --- | --- |
| `catalogue` 且外径有效 | 显示推导间隔，保留目录来源与圆柱模型说明 |
| `bore-estimate` | 显示估算标记；管底分组也标为估算，须预览确认 |
| `missing`、非法外径或来源无法证明 | 不补零、不使用包围盒宽度冒充外径；保留中心距，间隔显示缺少可靠外径 |

旧接口仅有 BRAN 顶层参考外径时，不把它自动套用于变径或明确缺失外径的段。

数值与状态规则：

- `G_nominal > 0`：正间隔。
- 接近零：按明确保存的数值容差显示名义接触；该容差不是工程合格阈值。
- `G_nominal < 0`：保留有符号值，显示「名义外径包络重叠」，不直接写成真实网格相交。
- 中心重合等退化情况不归一化零向量、不伪造可画的表面端点，改用文字提示。
- 「推导」是固定的方法说明；估算外径额外显示 `≈`，不能只靠数值是否带 `≈` 区分真实实体精算。

### 4.3 为什么第一版不使用整 BRAN 实体净距

现有 `/api/v1/spatial/surface-clearance` 按整对象查询，最近点可能位于本排之外的弯头、阀门或回折段。只在前端过滤返回的点也不够，因为响应没有提供区段内的次近结果。

未来如需区段实体净距，后端应支持限定参与叶子、隐式管身和轴向区间；该能力另立阶段，不在本版用公式或整 BRAN 最小值冒充。

## 5. 识别与相邻配对算法

### 5.1 获取输入与保留证据

- 固定本次选中 BRAN、模型上下文、模型版本与任务序号。
- 编号归一化、去重，但不把输入顺序当作几何顺序。
- 获取每根 BRAN 的真实中心线，校验编号、有限坐标、外径证据和警告。
- 缓存必须隔离上下文与模型版本；版本未知的数据不能无限期复用或仅凭缓存标为当前。
- 第一版不自动搜索并加入用户未选的管道。

### 5.2 构建直段

复用并适度补强 `buildStraightRuns`：

- 按成员 `order` 处理，弯头断链、变径拆段。
- 共线、同径之外，补充端点连接检查，禁止跨缺失区间合并。
- 无效段和中心线缺口必须有可见诊断，不能因跳过后继续合并而制造假直段。
- 同轴阀门、法兰可以提供轴线连续性，但其外形不属于本版管外径推导间隔。

### 5.3 管向分组

- 将正反向轴归一为同一无向方向。
- 按角度容差分组，不能仅做链式连通合并：A 接近 B、B 接近 C，并不保证 A 与 C 同样满足容差。
- 使用稳定代表方向及明确的组内角度约束；结果不依赖选择顺序和相机视角。

### 5.4 共同区段划分

- 将各直段端点投影到代表管向。
- 按起止事件扫描，划分参与集合稳定的有效区间。
- 不把「A 与 B 重叠、B 与 C 重叠」推导为 A/B/C 存在共同截面。
- 只保留达到最小共同长度的区间；参数须保存以便复算。

### 5.5 截面内归排与排序

- 默认取有效共同区段中点作为测量截面。
- 计算各真实轴线与截面的交点，投影为截面二维坐标。
- 中心模式：以确定性的候选排向、支持点数量、最大残差等识别候选排；多解进入人工确认。
- 管底模式：按支承法向和逐管半径计算底点，再识别排与排向。
- 禁止用逐点链式接近无限扩张容差，导致两排被粘成一排。
- 显示可解释证据，不把启发式评分冒充统计置信概率。

### 5.6 只生成相邻关系

每排按排向坐标排序，仅生成 `i ↔ i+1`。同一 BRAN 自配对、重复直段和零长度退化输入必须排除。

区间连续、相邻关系与参与直段身份相同的结果可合并；不跨缺口合并。不同弯折区段允许保留同一 BRAN 对的多条测量。第一版默认每个合并后的有效区段取一个截面标注。

距离筛选不能改变真实邻接：隐藏一条超阈值关系后，不得越过中间管补连更远管道。

### 5.7 输入不完整时的处理

缺少某根已选管道中心线时，不能静默删除它，再把剩余两根当成真正相邻。

保守规则：提供带缺失清单的预览；无法证明完整的分组不生成正式邻接结果。用户可排除失败输入并重新确认。外径缺失但中心线完整时，中心模式与中心距仍可继续，管底模式及推导间隔单独报告缺证据。

## 6. 建议参数与待确认项

以下是工程建议，不代表用户已确认具体数值。

| 参数 | 初始建议 | 说明 |
| --- | --- | --- |
| 管向分组角度 | 0.5° | 沿用现有平行直段识别起点；不因此宣称区段恒定净距 |
| 共线偏差 | 1 mm | 沿用现有共线容差作为起点 |
| 端点连接容差 | 1 mm | 新增连接检查，需用真实数据核对 |
| 成排位置偏差 | 1 mm | 新参数，建议可配置，须专业确认 |
| 最小共同长度 | 1 mm 几何门槛 | 沿用现有重叠阈值作为下限；是否提高工程有效长度待确认 |
| 测量截面 | 合并后共同区段中点 | 保存位置，不能随镜头移动 |
| 支承法向 | 世界向上在截面内的投影 | 退化时必须人工指定 |

不要复用一个「最大距离」同时承担搜索半径、邻接规则、列表筛选和验收阈值。原所有管对模式的参数保持原口径；连排模式的筛选单独定义，并确保列表与三维一致。

## 7. 结果身份、领域扩展与持久化

### 7.1 单一结果真相

继续由统一结果系统保存度量。新增管排分组元数据只保存成员、轴向区段、截面、识别模式、证据及结果 ID 引用，不复制第二份数值数组。

中心距与推导间隔是不同度量，各自有方法、证据和状态，不共用一个数值再由 UI 临时改名。

### 7.2 身份规则

新身份至少区分：

`连排命名空间 + 无向直段对 + 区段/测量截面身份 + 度量口径`

- 使用稳定的成员/隐式管身身份与测量输入，不能用显示序号、选择顺序或四舍五入后的距离作为身份。
- 对调 A/B 不产生重复。
- 同一对 BRAN 不同直段区段可以并存。
- 模型版本保存为证据并参与过期判断，不仅因为一个 ID 看起来相同就静默沿用旧值。
- 必须通过统一领域入口生成、校验身份，不由组件私自拼 ID 绕过快照校验。
- 旧记录缺少新维度时保持原身份语义，不全局重写既有记录 ID。

### 7.3 方法、快照与精度

编码前应正式扩展领域契约：

- 增加圆柱模型推导方法及对应精度表达，明确「推导」与「真实外表面精算」的区别。
- 逐侧保存外径值与来源，估算证据不能丢失。
- 支持有符号名义间隔及名义接触/包络重叠状态，不滥用真实网格的 `intersects`。
- 内部继续采用 design-world 米，接口毫米只在边界换算；显示舍入不得改变计算值或身份。
- 更新枚举校验、方法标签、精度展示、序列化和恢复逻辑，避免仅加一个字符串绕过类型与校验。
- 建议用带度量类型的可判别结构区分最近距离、截面中心距与有符号推导间隔；通用列表、筛选、尺寸转换和导出必须先判断口径，不能继续无条件把所有值当作非负的 `snapshot.distanceM`。
- 新增连排命名空间后，复核现有 `isPipeClearanceRecord` 等只按 BRAN 类型筛选的消费者，避免新度量被旧视图错误解释；旧快照缺少新字段时走明确的兼容分支。

### 7.4 原子提交与过期请求

整组更新采用「先构造、后验证、再一次提交」：

1. 捕获上下文与任务序号。
2. 完成数据获取、分组与记录构造。
3. 验证全组结果及证据。
4. 再次检查上下文与任务序号。
5. 原子替换本连排组的记录和引用；保留其他测量结果。

不能先删除旧记录再构造新记录，以免中途失败留下半成品。空结果、异常、取消等所有分支同样检查失效标记，禁止迟到请求写回已清空或已切换的上下文。

恢复旧快照和模型换版继续使用 stale 语义。新增快照需版本化并兼容旧内容；本机保存失败和校审提交状态分别如实展示。

## 8. 界面与三维标注

建议在现有抽屉中提供：

1. 模式：所有管对 / 连排相邻。
2. 成排依据：管中心 / 管底对齐。
3. 识别预览：各排高亮、成员顺序、共同区段、缺证据与歧义项。
4. 用户确认后生成相邻测量。
5. 每个相邻管对展示中心距与推导间隔，允许独立开关。

三维约束：

- 同排使用统一标注侧与偏移基线；两种度量分层，避免重叠。
- 中心距端点在轴线上；正推导间隔仅在模型假设成立时绘制相应圆柱表面点，并保留方法标记。
- 名义重叠、缺证据和退化情况使用明确文字，不画伪造的正净距线。
- 列表、三维、计数、导出使用同一可见集合。
- 当前排的隐藏、筛选和显示开关只影响本排，不切换全局其他净距标注。
- 标注渲染归属必须唯一：建议仍由统一外部源绘制，通过命名空间感知的可见集合处理分组开关；不要同时挂第二个来源又让旧同步器重复绘制同一记录。全局开关与单排开关各司其职。
- 行点击定位当前测量截面和两侧直段，不只飞到整条 BRAN 包围盒。
- 过期、重算失败旧值、推导、外径估算等状态在单行可见。
- 自动外部标注仍为只读展示；显式转换为用户尺寸时保留来源和方法，不自动制造第二份可编辑真相。

## 9. 建议模块拆分

以下路径为实施建议，不是本次新增源码清单。

| 层 | 建议位置 | 职责 |

## 10. 实施顺序与退出条件

### 阶段 A：契约与纯几何

- 确定领域身份、方法精度、带符号间隔和完整性规则。
- 实现直段连接检查、共同区段、两种归排、相邻配对。
- 对同一输入排列变化得到相同的几何关系和稳定身份。

退出条件：可用确定性输入验证主要几何边界，算法不依赖 Vue、相机或网络。

### 阶段 B：预览与度量

- 中心线服务、版本与证据处理。
- 抽屉模式切换、分组预览、用户确认。
- 中心距、外径推导间隔及缺证据展示。

退出条件：不把歧义分组、缺失管线或估算来源伪装为可靠正式结果。

### 阶段 C：结果与三维接入

- 原子提交、独立可见集合、只读标注。
- 隐藏/筛选/定位一致，反向选择不重复。
