## 效果图体现的三维标注规则（供 T1–T3 实现与验收引用）

记 `cheight` = 契约 `meta.cheight_mm`（本样本 27 mm），`h` = 文字帽高（设计空间，米）：
`h = max(cheight, 13 px × worldPerPixel(尺寸线中点))` —— 三维字高有一个屏幕下限（S2 的钳制思路搬到模型空间），
远景不至于缩成一条线，近景按 cheight 随模型放大。**本效果图所有尺寸都以 h 为单位，因此整套标注随相机远近保持比例。**

1. **尺寸线离开管体**（三维）：沿求解器 `dim_dir`（= 契约 `extension_lines` 方向）把尺寸线放到离管轴
   `D = r_surf + 1.2·h + row·1.7·h`（`r_surf` 取本 BRAN 最短的轴→尺寸线距离 = 求解器 row 1 的 od，row 由求解器行位反推：
   atta row 0 / 有 atta 时 main row 1）。尺寸界线从管体表面外 `0.15·h` 起、超出尺寸线 `0.3·h`。
2. **数字在三维里沿尺寸线排布**：文字所在平面**包含尺寸线**、并绕尺寸线轴旋转到尽量面向相机（三维 CAD 常规做法），
   基线取 ±`pipe_dir` 中在屏幕上从左向右的那个，"上"取基线在屏幕上逆时针 90° 的那侧（ISO 129-1 §4.1.1 从下方 / 右方可读；
   GB/T 4458.4 §4.3.1 数字在尺寸线上方）；字底离尺寸线 `0.3·h`；不打断尺寸线；带白色描边光晕压在管体上也可读。
3. **实心箭头**（三维）：顶点在尺寸线端点、长 `0.9·h`、半宽 `0.3·h`，与文字同平面（面向相机）；尺寸线短于
   「文字宽 + 两个箭头 + 8 px」时箭头外置、数字放到尺寸线延长线外侧（ISO 129-1 §5.7.3 a）。
4. **颜色 / 字重**：尺寸线、尺寸界线、箭头 `#c81e1e`（1.4 / 1.0 px 屏幕线宽）；数字粗体 `#111827` + 白色光晕。
5. **LOD 与去重**（沿用 S3 + S1 提案）：远景只画 main（atta 隐）；尺寸线投影短于文字宽者隐；**成对相压按确定性顺序隐去一条**
   （main > atta → 线长÷文字宽大者胜 → id）——远景图里 `173` 因与 `567.89` 相压被隐，中景图里 `907.52 / 402`（atta）被隐。
6. **标签块**（保持屏幕朝向的 billboard，三维锚点）：端点 connection tag（X / Y / PE，含接管说明）= 白底圆角卡片 + 灰色引线 +
   管端圆点，放在管端外侧偏上；元件 name tag = 黑框方框；弯头 `PE` 标高远景隐藏、中景起以小药丸显示（角度值近景才显示）；
   坡度、skew 辅助线 / 文字、branch-name 远 / 中景不显示。
7. **视向退化**：尺寸线投影长度不足 `0.35·h` 屏幕当量（线几乎沿视线）时文字改为屏幕水平贴在线中点（GB 方法 2 的精神）；
   本两张图里没有触发。

## 已知问题（效果图层面，供拆活时明确）

- 阀门颈部（`900.51 / 173 / 567.89` + name tag + Tail 坐标块 + `PE +18665`）在中景仍拥挤：成对去重需扩展到
  「文字 vs 尺寸线 / 卡片 / 药丸」，卡片与药丸的放置需要避让（当前只按方向外推固定距离）。
- 坐标卡片可能压住管件（阀门手轮）或压住别的尺寸文字（中景 `2640.89`）：卡片放置需考虑管件包围盒与已放文字。
- `r_surf` 取自求解器 od；若实际 DTX 管径含保温层等，需换成模型半径。

## 实现状态（2026-09-12）

规则 1–5、7 已按本文落地为默认呈现（ADR 0057）：`src/dimension/kernel/layout/dimension3d.ts`（几何与文字平面）、
`kernel/layout/declutterPolicy.ts`（规则 5 的成对去重）、`viewport/scenePainter.ts`（三维字形 + 光晕）、
`adapters/mbdV2ExternalAnnotations.ts`（`dimension3d` 输入）；`?mbd_3d=0` 回到原位平面呈现。与本文的差异：字高下限
用主题 `textHeightPx`（13 px，同本文）；箭头半角取主题 `arrowHalfAngleDeg`（18°，本文 0.3/0.9 ≈ 18.4°）；数字从两端
放不下时统一放到**终点**外侧（本文同）。

规则 6（同日稍后，ADR 0058）已落地：`kernel/layout/tagBillboard.ts` 把 `label` 呈现为屏幕定尺的 billboard——端点
connection tag = 白底圆角卡片 + 灰色引线 + 管端圆点，元件 name tag = 黑框方框，弯头 tag / 分支名 = 无边框药丸；
`adapters/mbdV2ExternalAnnotations.ts` 把每条 `leader_line` 配进它的 `label` 记录（先按 `<label id>:leader` 命名、再按引线起点
配对），引线始终指回管上的点、随标签一起隐藏 / 选中。三级 LOD：坐标卡片与位号任何距离都显示；弯头药丸从中景起（`secondary`，
投影字高 ≥ `sourceTextHeightMinPx`）、角度行只在近景（`detail`，≥ `sourceTextHeightMaxPx`）；分支名、坡度、skew 辅助线 / 文字
均为 `detail`。「已知问题」里的卡片避让做了一半：标签体在首选位（沿管外 `away` 方向、带向上偏置）被尺寸数字或别的标签压住时，
按卡片 → 方框 → 药丸、同类按 id 的确定顺序依次换到下一个候选位（绕首选方向 ±30° / ±60° / ±90° / ±135° / 180°，再放大 1.6 倍
standoff；先试整块在屏内的位置），全部被占则回首选位；**不避让管件几何**（卡片仍可能压在阀体上），也不避让三维尺寸线本身。
与本文的差异：字高用主题 `theme.tag`（卡片 / 方框 11 px、药丸 10 px）、drawing 风格的 standoff 也是主题常量；`mbd_3d=0` 同时
剥掉 `tag`，标签回到原位平面文字。实机截图与统计：`docs/verification/mbd-3d-dimension-presentation-2026-09-12/`（`tags-*.png`）。

「已知问题」第二条的另一半（2026-09-13，ADR 0059）：标签体现在也让开**管件包围盒**、**三维尺寸线**与**视口右上角的坐标 gizmo**——
宿主按设计空间区域交出构件包围盒角点（DTX 图层可见对象的局部 AABB），内核投影成凸包；其它布局的尺寸线 / 尺寸界线 / 箭头边 / 引线段是
障碍线段；gizmo 的命中区 div 按容器坐标交出，作为障碍矩形。候选位扩到四圈（standoff × 1 / 1.6 / 2.4 / 3.4），先取零侵入的位置，
没有则取加权侵入面积最小者（数字 / 标签 / gizmo > 描边 > 构件凸包），有整块在屏内的候选位时不为躲障碍出屏。实测中景尾端卡片与位号
离开阀体；近景阀门凸包盖住半个画布时取最少侵入位、引线变长；远景位号方框让开 gizmo 落到画布顶部中央。仍不做：网格轮廓、引线避让。
