REVIEW TASK · STATE MACHINE

三维校审任务状态机

以 review_tasks.status 为主语，展示 draft / submitted / in_review / approved / rejected / cancelled 六状态间的迁移动作与守卫。

HAPPY PATH

唯一成功通道

  • draft → submitted → in_review → approved
  • 只有 pz 节点的 submit_to_next 会真正把 status 改为 approved
  • approved 一旦落地，链路终止，不会再产生新批注或流转

HUB & SELF-LOOP

in_review 承担三节点

  • jd/sh/pz 三节点状态字段都是 in_review，用 current_node 区分
  • 节点推进由同一个 submit_to_next API 完成，配合 has_permission 鉴权
  • return_to_node 把状态硬拉回 draft，并改写 current_node

TERMINATION

三类终态

  • approved — 合规完成
  • rejected — pz 显式打回（reject_task）
  • cancelled — 任意非终态可被 cancel_task 关停
