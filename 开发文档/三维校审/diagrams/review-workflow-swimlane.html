REVIEW WORKFLOW · SWIMLANE

三维校审工作流

以四节点链路（sj → jd → sh → pz）展示任务在不同角色之间的流转、状态机转换与退回路径。源自 三维校审流程与批注处理审核 — 2026-04-19。

NODE CHAIN

线性四段链路

  • sj → jd → sh → pz：与 review_api.rs :2670 get_next_node 一致
  • 每个节点绑定一个字段决定"谁能操作"（requester_id / checker_id / approver_id）
  • pz 的 approve 是唯一终态正向出口

STATE MACHINE

任务状态转换

  • draft → submitted → in_review → approved 是 happy path
  • return_to_node 允许回退到任意更早节点，落回 draft
  • reject_task 与 cancel_task 是独立终态，不可再流转

DATA FLOW

批注与工作流协同

  • 确认批注 → POST /api/review/records（ConfirmedRecord）
  • 节点流转 → POST /tasks/{id}/submit + workflow_history
  • PMS 嵌入经 workflow/sync 聚合恢复状态
