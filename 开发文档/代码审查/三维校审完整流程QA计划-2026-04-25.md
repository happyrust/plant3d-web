# 三维校审完整流程 QA 计划（2026-04-25）

## 目标

验证三维校审从发起、流转、批注处理、门禁拦截、驳回返工到恢复打开的完整链路，并整理可复现问题与后续解决方案。

## 覆盖范围

### 主链路

1. SJ 发起三维校审。
2. SJ 执行 active/送审。
3. JH/JD 打开校审任务并处理批注。
4. JH/JD 同意后继续流转。
5. SH/PZ 继续确认到终态。

### 分支链路

1. 门禁 block：存在未处理或待确认批注时不能继续流转。
2. 门禁 return：存在被驳回/需退回状态时提示退回。
3. JH/JD 驳回到 SJ，SJ 重新打开并进入批注处理路径。
4. stop/终止流程进入 readonly。
5. 刷新恢复：reviewer 刷新后仍恢复到正确 form/task/workflow 状态。

### 批注处理

1. 文本、云线、矩形批注参与门禁。
2. OBB 作为辅助证据，不阻塞流转。
3. “已修改 / 不需解决 / 同意 / 驳回”状态变化与备注要求。
4. 批注详情打开、表格打开、筛选状态下定位。
5. 评论、回复、编辑、删除的可见性与错误处理。

## 执行方式

### 自动化验证

优先使用现有 Playwright 用例和仿 PMS 模拟器：

```bash
npm run test:e2e -- e2e/pms-review-simulator-token-only.spec.ts e2e/review-initiate-ribbon.spec.ts
```

如本地服务和后端条件满足，再运行模拟器全链路：

```bash
npm run test:pms:simulator
```

### 浏览器探索

使用本地 Vite 页面和 `agent-browser` 对以下入口进行探索：

- `/pms-review-simulator.html?debug_ui=1&project=AvevaMarineSample`
- `/?output_project=AvevaMarineSample&show_dbnum=7997`

探索时保留截图、控制台错误、可复现步骤。
